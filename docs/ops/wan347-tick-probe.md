# 1분보다 잘게 보는 데이터 — 하루치 실측 런북 (WAN-347 §0)

**한 줄**: `alphablock tick-probe`가 대표 종목의 하루치를 **실제로 받아 실제로 넣어 보고**
행 수·압축 후 바이트·SQLite 바이트·시간을 찍는다. **이 PR은 그 자(measuring stick)까지다** —
상시 수집기(§1)도 의심 구간 백필(§2)도 만들지 않았다(이슈 완료기준 3).

## 서버에서 한 번 돌리기

```bash
cd /opt/alphablock   # 배포 경로
nice -n 19 ionice -c 3 uv run alphablock tick-probe \
  --day "$(date -u -d yesterday +%F)" \
  --csv reports/wan347_tick_probe.csv
```

* `--day`를 안 주면 **어제(UTC)** 다. 오늘치 아카이브는 아직 없다.
* `--nice`는 기본 19라 프로세스가 자기 우선순위를 알아서 낮춘다. **`ionice -c 3`은 셸에서
  걸어야 한다** — 디스크 경합이 이 박스의 병목이다(WAN-318 §1).
* 기본 대표 3종목은 `BTCUSDT SOLUSDT TRXUSDT`(활발·중간·한산). **12종목 정확한 값이
  필요하면 그냥 다 재라** — 아카이브는 종목당 요청 한 번이다:
  `--symbols BTCUSDT ETHUSDT SOLUSDT BNBUSDT XRPUSDT TRXUSDT DOGEUSDT LINKUSDT LTCUSDT ADAUSDT DOTUSDT BCHUSDT`
* 급하면 `--no-sqlite`로 적재를 건너뛴다(행 수·압축 크기만 — **DB 비용은 못 잰다**).

**읽기 전용이다**: 프로덕션 DB를 열지도 않고(파일 크기만 `stat`) 잰 파일은 스크래치에
두었다 지운다. 남기려면 `--keep`(1GB 박스이니 보고 나서 지울 것).

**종료 코드**: 이슈가 물은 두 자료(선물 체결내역 · 현물 1초봉)를 **둘 다** 재면 0, 하나라도
못 재면 1이다 — 반쪽 표가 「성공」으로 나가지 않게 한다.

## 러너를 밀어내지 않았는지 확인 (완료기준 4)

돌리기 **전과 후**에 러너 한 바퀴 시간을 본다:

```bash
uv run alphablock status | grep -i -e 러너 -e 사이클
```

`--jobs` 같은 병렬 노브는 이 명령에 **없다**(일부러). 아카이브를 순서대로 받고 순서대로
넣는다 — 이 박스에서 `--jobs 2`가 `sys` 3.2배·벽시계 +22%였다는 실측(WAN-338)이 있어
병렬을 기본으로 두지 않았다.

## 표를 어떻게 읽나

| 열 | 뜻 |
| -- | -- |
| 행 수 | 그 종목·그 하루의 실제 행 수 |
| 받은(zip) | 아카이브 zip 크기 = **압축 후 디스크** |
| 푼 CSV | 압축을 푼 원본 CSV |
| gzip(최소열) | 필요한 열만 남겨 다시 gzip한 크기 = **파일로 보관** 안의 비용 |
| SQLite | candidate 테이블에 실제로 넣었을 때의 DB 파일 크기 = **DB에 넣기** 안의 비용 |
| 받기s / 넣기s | 받는 시간 / 넣는 시간 (**이 둘만 머신에 따라 달라진다**) |

🚨 **행 수와 바이트는 머신과 무관하다**(거래소가 준 파일 · 같은 코드의 결정적 산출).
**시간만 이 박스의 값**이다 — 그래서 서버에서 다시 돌린다. 로컬 값을 서버 기준으로 옮기는
것이 이 저장소가 두 번 틀린 그 실수다(WAN-203 셀 비용 2배 과대 추정 · WAN-194 doctor 12초).

## 알아 둘 것 — 도구가 실측으로 밝히는 두 가지

1. **USDⓈ-M 선물에는 1초봉이 없다.** REST가 `-1120 Invalid interval`로 거절하고 아카이브에도
   `1s` 디렉터리가 없다(404). 1초봉은 **현물 전용 상품**이라, 쓰려면 우리가 매매하는 시장이
   아닌 곳의 가격으로 봉내 순서를 추정하게 된다. 표는 그 칸을 지우지 않고 **「없음」으로**
   남긴다.
2. **선물 체결내역 REST는 최근 2일만 준다**(`-4166 Search window is restricted to recent 2
   days only`). 즉 **§2(의심 구간 과거 백필)는 REST로 불가능**하고 일자별 아카이브가 유일한
   길이다.
