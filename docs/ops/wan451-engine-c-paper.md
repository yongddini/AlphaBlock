# 엔진 C 페이퍼 켜기 — WAN-451 ② 단계 런북

> 사용자 결정(2026-10-14): 범위 B 단계적. ② 단계는 **옛 오더블록 페이퍼를 끄고(병행 없음 ⑦)
> 엔진 C(BTC·ETH 시계열 모멘텀)만** 페이퍼로 돌린다. 팔(③ 단계)은 아직 없다.
> 실주문은 없다 — `ALPHABLOCK_LIVE_TRADING=false` 그대로다.

## 순서 (리셋 이음매 — 한 번에)

1. **이 PR이 배포됐는지** 확인한다(`git log` · `alphablock --help`가 뜨는지).
2. `.env`에 두 줄을 넣는다(값을 바꾸는 것만으로는 아무 일도 안 일어난다 — 재시작이 필요하다):

   ```
   ALPHABLOCK_LIVE_ZONE_LIMIT_ENABLED=false
   ALPHABLOCK_LIVE_TSMOM_ENABLED=true
   ```
3. 리셋한다 — 옛 장부를 CSV로 남기고 비운 뒤 러너를 재시작한다:

   ```bash
   sudo scripts/paper-reset.sh --yes
   ```

   리셋은 이제 `live_engine_state`·`circuit_breaker_notice`(그리고 있으면 엔진 C 원장 둘)도
   함께 내보내고 비운다 — 옛 규칙의 엔진 스냅샷이 재기동 때 복원돼 섞이지 않게 한다.
   ⚠️ `data/live_runtime_state.json`(Health 탭용 상태 파일)은 파일이라 스크립트가 안 지운다.
   옛 대기 주문·포지션 표시가 남아 보이면 러너를 멈춘 상태에서 지운다.
4. 다음 00:00 UTC(KST 09:00) 뒤 첫 폴링에 첫 리밸런싱이 난다. 확인:

   ```bash
   sqlite3 data/ohlcv.db "SELECT asset, datetime(as_of_ms/1000,'unixepoch'), weight, target_notional, cost FROM tsmom_rebalances ORDER BY as_of_ms DESC LIMIT 4;"
   ```

## 알아 둘 것

- **러너가 죽어 있던 날은 소급 거래하지 않는다.** 그 기간은 보유를 그대로 둔 채 다음
  리밸런싱에서 가격 손익·펀딩을 한 번에 정산한다(로그·알림에 「N일 공백」). 그만큼 매일
  리밸런싱하는 백테스트와 다르다 — 장부에서 `as_of_ms`가 하루 넘게 건너뛴 행으로 보인다.
- **일봉에 구멍이 있으면 그 자산은 리밸런싱을 보류한다**(지어내지 않는다 — 「N일 전」이 다른
  날을 가리키게 된다). 텔레그램에 「보류」가 한 번 오고, 일봉이 채워지면 다음 폴링에 정산한다.
  구멍 메우기: `uv run alphablock backfill --repair`.
- **첫 250일 이력**: BTC·ETH 1d는 수집기가 이미 수년치 갖고 있다(룩백 1825일) — 첫날부터
  배율이 정의된다. 이력이 모자라면 배율 0(포지션 없음)으로 기록된다.
- 비용은 **실제 거래 명목 × 9bp**로 물린다(백테스트는 배율 변화 × 9bp — 2차 항 차이,
  `paper/tsmom_ledger.py` 독스트링).
- 되돌리기도 **리셋 이음매에서** 한다(두 스위치를 원래 값으로 + `paper-reset.sh`). 엔진 C를
  끄면 지갑 자본 복원이 엔진 C 원장 합을 더하지 않고, 마지막 엔진 C 보유도 더는 정산되지
  않는다 — 리셋 없이 끄면 지갑이 그만큼 어긋난다.

## 어디서 보나

- **텔레그램(매일 KST 09:00 직후)**: 「📈 엔진 C 리밸런싱」 — 자산별 방향·배율·상승 신호 수·
  거래·정산·펀딩·비용과 지갑 자본. 롱↔숏 전환은 🔁로 표시된다.
- **대시보드 「잔고 · 거래내역」 탭**: 아래쪽 「엔진 C (추세추종 · BTC·ETH)」 블록 — 지갑 잔고
  (팔 + 엔진 C) · 엔진 C 누적 손익 · 하루 1회 시가평가 기준 MDD · 지금 보유 · 시가평가 자본
  곡선 · 리밸런싱 원장. 팔 거래가 아직 없어도 이 블록은 보인다(엔진 C가 기록을 남겼으면).
  ⚠️ 위쪽 카드·에쿼티 곡선은 **팔 몫만**이다(그래서 엔진 C가 있으면 「지갑 잔고(팔 몫)」로 표시).
- **다이제스트**(`scripts/paper_digest.py`): 끝에 「엔진 C (추세추종)」 줄이 붙는다 — 보유 ·
  기간 리밸런싱 일수·정산·펀딩·비용 · 시가평가 자본과 기간 낙폭. 다이제스트는 원래 스케줄이
  없다(기본 꺼짐). 하루 1회 받으려면 서버 크론에 한 줄(`.env`에
  `ALPHABLOCK_PAPER_DIGEST_ENABLED=true`):

  ```
  10 0 * * * cd ~/AlphaBlock && uv run python scripts/paper_digest.py --days 1 >> data/digest.log 2>&1
  ```

  (UTC 00:10 = KST 09:10 — 그날 리밸런싱이 끝난 뒤. 서버 시간대가 UTC가 아니면 맞춰 바꾼다.)

```bash

```

맞대고, 체결가가 그날 종가인지 · 목표 명목이 `정산 후 자본 × λ·k·0.5·배율`인지 본다. 하나라도
다르면 종료 코드 1이다(같은 함수 · 같은 데이터라 갈라질 이유가 없다 — 일봉이 나중에 고쳐졌거나
배선이 틀렸다는 뜻). 러너가 꺼져 있던 날은 「건너뛴 날」로 따로 보여 주고 실패로 세지 않는다.
