# WAN-228 — 익절 후 존 내 재진입 census ((B) 구멍의 크기 · GO/STOP 게이트)

**성격** 측정 전용(기본값·토대 불변 · `ALPHABLOCK_LIVE_TRADING=false` 유지). 사용자 질문
(*"나는 B를 알아야 해"*, 2026-08-02)에 답한다. WAN-223/226이 잰 것은 **(A)** 만료 후 재탭
실패로 **첫 진입**을 놓치는 구멍(채택 진입의 11.7%)이었다. 이 이슈는 **(B)** 를 잰다:
**익절(고정 1.5R) 후 포지션이 닫힌 뒤, 같은 존이 아직 유효한데(무효화 `break_time` 이전)
가격이 진입 지정가로 되돌아오면 재진입해야 하나?** 채택 기본값 그대로(`ConfluenceParams()`·
`OrderBlockParams()`) 돌리며 옛 핀(`LEGACY_*`)을 하나도 물려받지 않는다.

**재현**

```
uv run python -m backtest.wan228_reentry_census --tf 4h,1h --jobs 8
uv run python -m backtest.wan228_reentry_census --from-csv   # 요약만 재생성
```

## 1. 무엇을 쟀나 — 사용자가 짚은 구멍

현행 엔진은 지정가 주문을 **탭(바깥→안 전이) 순간**에만 만든다(`strategy/order_blocks.py`의
`inside and not _inside` — 존 안에 머무는 연속 봉은 첫 진입만 기록). 그래서 익절로 포지션이
닫힌 뒤 가격이 존 안에서 오르내리며 진입 지정가로 되돌아와도 **새 탭이 없어 주문을 다시
걸지 않는다.** 사용자 직관: *"그렇게 진입 못하는 순간도 많을 것 같다."* WAN-90이 익절 후
**E[러너]≈0R · 본절 복귀율 97~99%(평균회귀)** 를 실측했으니, 가격이 자주 되돌아온다는 것
자체가 (B) 재진입 기회가 자주 생긴다는 뜻이다(단 그 기회가 **수익**인지는 별개 — §4 경고).

## 2. 방법 — 익절마다 지정가 재무장 (엔진 시뮬레이터 재사용)

WAN-223 (A)는 두 패스(`limit_valid_bars=24` vs `None`) 차이로 쟀지만, **재무장은 채택 엔진이
하지 않는 유일한 동작**이라 (B)는 그 두-패스 차이로 잴 수 없다. 그래서 채택 엔진으로 전
구간을 돌려 실제 채택 거래를 얻고(`build_zone_limit_candidates` → `sequence_with_candidates`
= 동시 1포지션), **익절(`TAKE_PROFIT`)로 닫힌 거래마다**:

* 그 존의 **실제 체결가**(`_Candidate.entry_price`)를 지정가로, 무효화 경계를 손절로, 고정
  1.5R을 익절 목표로 삼아,
* 익절 **직후**부터 존 무효화(`break_time`)까지 **주문을 다시 걸고**(`limit_valid_bars=None`
  = 무기한 대기 = 형성-즉시 예약의 체결 대리, WAN-223 §1 정의),
* `simulate_zone_limit_trade`(엔진과 **같은** 체결·손절·익절·무효화 로직)로 체결을 본다.
  체결 = **(B) 후보 재진입 1건**. 익절로 닫히면 다시 무장(가격이 또 되돌아올 수 있다),
  손절(존 무효화)·미체결·데이터끝이면 그 존은 끝난다.

지정가는 원래 체결가로 **고정**한다(이슈 §1 정의 *"가격이 다시 밴드 가격(진입 지정가)에
닿는"*). 봉내 라이브 밴드(`intrabar_live`)는 매 서브스텝 움직이지만, (B) **크기의 상한**을
재는 census라 재진입 문턱을 원래 체결가로 고정한다(밴드 재산정 재진입은 층 2 sim 소관).
회귀 테스트가 재무장 루프(익절→재무장, 손절→중단)·무효화 컷·판정 자를 동작으로 고정한다
(`tests/test_wan228_reentry_census.py`).

⚠️ **15m은 이 표에 없다 — 무거운 후속 컴퓨트로 남긴다.** 재무장 루프가 익절 존마다 존
무효화까지 서브스텝을 스캔해 15m·6년에서 초선형으로 느리다(단일 15m 셀 base가 ~37분,
WAN-203 · 재무장 오버헤드가 그 위에 얹힌다). 4h·1h가 두 작업 TF의 대표이고 GO/STOP 판정을
결정하며, 15m 전 구간은 WAN-227의 무거운 15m 패스와 합쳐 도는 후속으로 남긴다(재현 명령은
위 블록에 `--tf 15m`). ⚠️ 15m은 「닿으면 체결」 낙관 가정에 가장 크게 의존해(봉이 짧아 존 안
오르내림이 잦다) (B) 재진입이 더 많이 나와도 **가장 못 믿을 숫자다**(이슈 경고).

## 3. 결과 (9종목 × 4h·1h · 못 박은 6년 · `baseline` 단독)

| TF | (B) 재진입 / 채택 진입 | 비율 | 따뜻한 OOS 격리 순수익(심볼평균) |
| -- | --: | --: | --: |
| 4h | 368 / 559 | **65.8%** | **+5.79%p** |
| 1h | 1318 / 2217 | **59.4%** | **+5.32%p** |
| 합계 | 1686 / 2776 | **60.7%** | **+5.56%p** |

* **(B) 구멍은 (A)의 5배가 넘는다** — 채택 진입 대비 **60.7%**(4h 65.8% · 1h 59.4%). WAN-223
  (A)의 11.7%가 이미 (c) 경계였는데, (B)는 그보다 압도적으로 크다. WAN-90의 평균회귀(익절 후
  본절 복귀 97~99%)가 그대로 재진입 기회로 나타난다 — 익절 존 하나당 평균 ~1.0~1.4회 되돌아와
  다시 체결된다.
* **격리 순수익은 심볼평균 +5.56%p로 유의 문턱(1%p)을 넘지만, 종목에 갈린다** — 1h OOS는
  9종목 중 **4종목이 마이너스**(DOGE −13.0%p · XRP −6.5 · BNB −5.2 · TRX +0.6는 사실상 0),
  4h는 2종목 마이너스(ETH −6.8 · XRP −2.0). 평균을 올리는 것은 소수 큰 승자다(LTC 1h +25.4 ·
  ETH 1h +18.9 · BTC 4h +18.0 · LTC 4h +17.2). WAN-222/223의 **"체결은 늘지만 수익은 종목에
  갈린다"** 가 (B)에서도 재확인된다.
* **재진입 승률은 절반 안팎이다** — OOS 버킷에서 익절/(익절+손절)이 대체로 45~60%. 재진입이
  공짜 알파가 아니라 채택 진입과 같은 성질(평균회귀에 올라탄 절반의 승부)임을 보여준다.

## 4. 판정 — **(a) GO(크기 기준) · 단 수익은 층 2 sim이라야 안다**

**(B) 재진입 = 채택 진입의 60.7% · 따뜻한 OOS 격리 순수익 심볼평균 +5.56%p.** 판정 자(코드
상수): 비율 ≥ 20% **그리고** 수익 델타 ≥ 1%p → (a) GO · < 5% **또는** < 1%p → (b) STOP ·
사이 → (c). 두 자를 모두 넘어 **기계적으로 (a) GO** 다 — (A)와 달리 (B) 구멍은 층 2
(resting-order sim = 재-베이스라인)를 지어 제대로 잴 만큼 **명백히 크다.**

🚨 **단 GO는 「재무장을 채택하라」가 아니라 「제대로 재 볼 값이 있다」는 뜻이다.** 세 겹의
한계가 이 수치를 상한으로 묶는다:

1. **격리 상한** — §2 손익은 각 재진입을 기준자본에서 **독립** 체결시킨 값이다. 동시 1포지션·
   자본·슬롯 경합·레버리지 북(WAN-213 cap_only 5배) 상한을 모델링하지 않는다. 실제로는 익절
   존이 재무장돼 있는 동안 다른 칸·다른 셋업과 슬롯·자본을 다툰다 — 실현 손익은 층 2
   resting-order sim이라야 정확하다.
2. **`baseline` 낙관 렌즈** — 늘어난 재진입 체결은 전부 "닿으면 체결" 위 값이다. 되돌아온
   지정가 터치는 실거래 큐 우선순위상 **가장 안 될 가능성이 높은** 체결이고(WAN-96 비대칭),
   그 실측은 틱·호가(WAN-98, Canceled) 없이는 반쪽이다.
3. **종목 편중** — 심볼평균 +5.56%p는 소수 큰 승자가 만들고 1h는 9종목 중 4종목이 손실이다.
   "(B)를 메우면 번다"가 종목을 안 가리는 성질이 아니다.

⚠️ **「엣지 없음」(WAN-84/88/111/114/124/151)은 그대로다** — 재진입은 알파가 아니라 체결/자본
배분의 **모양**만 바꾼다. 이 표는 그 모양의 크기 조사이지 새 엣지의 발견이 아니다.

## 5. 층 2 착수 — 사용자 결정 (개발자 임의 착수 금지)

판정이 (a) GO(크기)이므로 **층 2 resting-order 시뮬레이터**(익절마다 주문 재무장 + 「가까운
주문 우선」 배분 + 자본·슬롯 경합·북 상한을 실제로 모델링)를 지을 값이 있다. 다만 그 착수는
**재-베이스라인 = 사용자 결정**이다(이슈 「범위 밖」 명시). 선행·주의:

* 층 2 sim은 WAN-226 §2가 짚은 대로 현행 북(`run_leverage_book`)의 **fill-replay** 구조를
  넘어서는 엔진 빌드다 — 분(分) 단위 전-칸 가격 + 미체결 주문 랭킹이 필요하다.
* 실체결 큐 우선순위(WAN-98) 없이는 §2의 낙관 상한이 얼마나 부풀려졌는지 못 잰다.
* 종목 편중이 커 채택은 심볼평균이 아니라 종목별로 봐야 한다(WAN-222/223 교훈).
* 라이브 배선은 WAN-45/171 소관이다.
