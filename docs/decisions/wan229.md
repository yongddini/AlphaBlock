# WAN-229 — 익절 후 존 내 재진입 census 15m 축 완결 ((B) §1c/§2 15m)

**성격** 측정 전용(기본값·토대 불변 · `ALPHABLOCK_LIVE_TRADING=false` 유지). [WAN-228](wan228.md)
(PR #187, (B) 구멍의 크기)이 완료기준 #1로 **15m·1h·4h 세 TF 전부**를 요구했으나 15m이
셀당 무거워(WAN-203) **4h·1h만 내고 15m을 미추진으로 남겼다.** 그 15m을 **완결**하는
스핀아웃이다 — GO/STOP 판정은 4h·1h로 이미 (a) GO가 났으니 **판정을 바꾸는 축이 아니라
그림 완성**이다. census 엔진(익절 후 지정가 재무장 루프·행 모델·판정·자)은 WAN-228 모듈을
**한 줄도 갈라지지 않게 그대로 재사용**하고 TF만 15m으로 돌렸다(핀 없음 · 채택 좌표
`ConfluenceParams()`·`OrderBlockParams()`).

**재현**

```
# WAN-228 census 엔진을 15m으로 직접(이슈 §3 재현 명령 · CSV만 분리):
uv run python -m backtest.wan228_reentry_census --tf 15m --jobs 9 \
    --out-cells backtest/reports/wan229_reentry_census_15m.csv \
    --out-md backtest/reports/wan229_reentry_census_15m_summary.md

# 또는 이 이슈의 얇은 래퍼로(같은 census 엔진 · 15m 기본 · WAN-229 제목 요약):
uv run python -m backtest.wan229_reentry_census_15m --jobs 9   # 무거움(셀당 ~37분, WAN-203)
uv run python -m backtest.wan229_reentry_census_15m --from-csv  # 요약만 재생성
```

원본: `backtest/reports/wan229_reentry_census_15m.csv` ·
요약: `backtest/reports/wan229_reentry_census_15m_summary.md`

실측 9종목 15m·못 박은 6년(2020-09-15~2026-07-22)은 8워커로 약 18분에 끝났다(예상 상한
셀당 ~37분보다 빨랐다 — CPU 포화라 실측만 기록). `jobs`는 성능 노브이지 결과 축이 아니다
(WAN-121).

## 1. 무엇을 쟀나 (WAN-228과 같은 (B) 구멍, 15m 축)

WAN-223/226이 잰 **(A)** 는 지정가 만료 후 재탭 실패로 **첫 진입**을 놓치는 구멍(채택 진입의
11.7%)이었다. **(B)** 는 다른 구멍이다: **익절(고정 1.5R) 후 포지션이 닫힌 뒤, 같은 존이
아직 유효한데(무효화 `break_time` 이전) 가격이 진입 지정가로 되돌아오면 재진입해야 하나?**
현행 엔진은 지정가 주문을 **탭(바깥→안 전이) 순간**에만 만들어(`strategy/order_blocks.py`의
`inside and not _inside`) 이 되돌림을 통째로 놓친다. WAN-90이 익절 후 **E[러너]≈0R · 본절
복귀율 97~99%(평균회귀)** 를 실측했으니, 가격이 자주 되돌아온다는 것 자체가 (B) 재진입
기회가 자주 생긴다는 뜻이다(단 그 기회가 **수익**인지는 별개 — §4 경고).

## 2. 방법 — 익절마다 지정가 재무장 (엔진 시뮬레이터 재사용 · WAN-228과 동일)

채택 엔진으로 전 구간을 돌려 실제 채택 거래를 얻고(`build_zone_limit_candidates` →
`sequence_with_candidates` = 동시 1포지션), 익절(`TAKE_PROFIT`)로 닫힌 거래마다 그 존의
**실제 체결가**를 지정가로, 무효화 경계를 손절로, 고정 1.5R을 익절 목표로 삼아 익절
**직후**부터 존 무효화(`break_time`)까지 **주문을 다시 걸고**(`limit_valid_bars=None` = 무기한
대기 = 형성-즉시 예약의 체결 대리), `simulate_zone_limit_trade`(엔진과 **같은** 체결·손절·
익절·무효화 로직)로 체결을 본다. 체결 = **(B) 후보 재진입 1건**. 익절이면 다시 무장, 손절·
미체결·데이터끝이면 그 존은 끝. 지정가는 원래 체결가로 **고정**한다(이슈 §1 정의 · 크기의
상한 · 밴드 재산정 재진입은 층 2 sim 소관).

§2 손익은 IS와 **따뜻한 OOS**(WAN-166)로 가른다 — 재진입의 **진입 시각**이 평가 경계 전/후
인가로 버킷. `격리 순수익`은 각 재진입을 기준자본에서 독립 체결시킨 `_to_trade` 순손익이다
(동시 1포지션·자본·슬롯 경합·북 상한 미모델링 = **격리 상한**).

**이 CSV는 WAN-228 4h·1h CSV(`wan228_reentry_census.csv`)와 열이 같아 교차검산된다** —
같은 `CellRow` 클래스, 같은 census 엔진, TF만 다르다.

* **(B) 구멍의 크기가 세 TF에서 안정적이다** — 15m 63.2%는 4h(65.8%)·1h(59.4%)와 같은

* **따뜻한 OOS 격리 순수익 +11.86%p는 4h·1h(+5.56%p)의 두 배가 넘는다** — 15m이 봉이 짧아
  같은 존 안 되돌림을 더 촘촘히 잡기 때문이지 (B)가 15m에서 "더 좋아서"가 아니다. 🚨 이
  수치야말로 **가장 못 믿을 숫자다**(§4-2): 15m은 세 TF 중 `baseline`(닿으면 체결) 낙관 가정에
  **가장 크게 의존**한다 — 되돌아온 지정가 터치는 실거래 큐 우선순위상 가장 안 될 체결이고
  (WAN-96 비대칭), 15m은 그 "스치듯 닿은 체결" 비중이 가장 크다.
* **드물게 종목 편중이 약하다 — OOS 마이너스는 LINK 1종목뿐이다**(1h는 9종목 중 4종목이
  마이너스였다). ETH를 빼도 +9.87%p, ETH·XRP를 둘 다 빼도 **+8.58%p**로 양수를 유지하고,

  이것을 「(B)가 15m에서 엣지다」로 읽지 말 것 — 낙관 렌즈 위 격리 상한이고, 「엣지 없음」은

  채택 진입과 같은 성질(평균회귀에 올라탄 절반의 승부)임을 보여준다.

## 4. 판정 — **(a) GO(크기 기준) · 4h·1h와 정합 · 단 수익은 층 2 sim이라야 안다**

**(B) 재진입 = 채택 진입의 63.2% · 따뜻한 OOS 격리 순수익 심볼평균 +11.86%p.** 판정 자(코드
상수, WAN-228과 동일): 비율 ≥ 20% **그리고** 수익 델타 ≥ 1%p → (a) GO. 두 자를 모두 넘어
**기계적으로 (a) GO** 이고, **WAN-228의 4h·1h (a) GO를 15m이 재확인**한다(세 TF 전부 GO).

🚨 **GO는 「재무장을 채택하라」가 아니라 「제대로 재 볼 값이 있다」는 뜻이다.** WAN-228과 같은
세 겹의 한계가 이 수치를 상한으로 묶고, **15m에서는 그 한계가 더 무겁다**:

1. **격리 상한** — §2 손익은 각 재진입을 기준자본에서 **독립** 체결시킨 값이다. 동시 1포지션·
   자본·슬롯 경합·레버리지 북(WAN-213 cap_only 5배) 상한을 모델링하지 않는다. 15m은 재무장
   존이 가장 많아(익절존 278~669개) 슬롯·자본 경합이 가장 심할 축이라 격리 상한과 실현
   손익의 간극이 가장 크다 — 실현 손익은 층 2 resting-order sim이라야 정확하다.
2. **`baseline` 낙관 렌즈(15m에서 최대)** — 늘어난 재진입 체결은 전부 "닿으면 체결" 위 값이고,
   15m은 세 TF 중 "스치듯 닿은 체결" 비중이 가장 크다(WAN-96/124 15m 체결 민감성). +11.86%p가
   4h·1h의 두 배인 것도 상당 부분 이 낙관의 몫이다. 실측은 틱·호가(WAN-98, Canceled) 없이는
   반쪽이다.
3. **종목 편중은 약하나 알파는 아니다** — 15m은 드물게 OOS 마이너스가 1종목뿐이지만(§3),
   그래도 낙관 렌즈 위 격리 상한이라 「(B)를 메우면 15m에서 번다」의 근거가 되지 못한다.

⚠️ **「엣지 없음」(WAN-84/88/111/114/124/151)은 그대로다** — 재진입은 알파가 아니라 체결/자본
배분의 **모양**만 바꾼다. 이 표는 그 모양의 15m 크기 조사이지 새 엣지의 발견이 아니다.
†=신규 종목(펀딩 0행 → 순수익 낙관, 재진입 **수**엔 무관).

## 5. 층 2 착수 — 사용자 결정 (개발자 임의 착수 금지)

세 TF 전부 (a) GO(크기)이므로 **층 2 resting-order 시뮬레이터**(익절마다 주문 재무장 +
「가까운 주문 우선」 배분 + 자본·슬롯 경합·북 상한을 실제로 모델링)를 지을 값이 있다. 다만
그 착수는 **재-베이스라인 = 사용자 결정**이다(이슈 「범위 밖」 명시). 선행·주의는 WAN-228 §5와
같다 — 층 2 sim은 현행 북의 fill-replay 구조를 넘어서는 엔진 빌드(분 단위 전-칸 가격 + 미체결
주문 랭킹)이고, 실체결 큐 우선순위(WAN-98) 없이는 §2 낙관 상한이 얼마나 부풀려졌는지 못
재며(15m에서 가장 부풀려짐), 라이브 배선은 WAN-45/171 소관이다.

**기본값·토대 불변**(측정 전용 · 오프셋 2bp · `intrabar_live` · `unconditional` · 고정 1.5R ·
롱 온리 · `combine_obs=False` · `max_zone_width_atr=1.28` · 북 cap_only 5배 · 실거래 보류
`ALPHABLOCK_LIVE_TRADING=false` 유지).
