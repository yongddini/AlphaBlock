# WAN-204: 익절 변형 — OB 윗경계까지 승자 연장 `max(1.5R, OB윗경계)` vs 현행 고정 1.5R

- **일자**: 2026-07-28
- **상태**: 측정(4h·1h 완료 · 15m 생성 중) — **기본값·토대 불변**(채택은 별도 재-베이스라인
  결정 = 사용자 결정, 개발자 임의 착수 금지)
- **재현**:

## 0. 질문 — 사용자 아이디어 (2026-07-28)

진입한 **바로 그 오더블록의 윗경계**를 익절 목표로 쓰되 현행 1.5R과 **MAX로 묶는다**:
롱 기준 `TP = max(진입가 + 1.5R, OB 윗경계)`. 최소 1.5R은 보장하고, OB 윗경계가 더 멀면
거기까지 승자를 연장한다.

📌 **진입 기하 (코드 확인)** — 롱 진입가는 **항상 OB 윗경계 이하**다
(`strategy/models.py:deviation_entry_price` 규칙 1·2: 밴드가 존 위면 근단=OB 상단 진입 ·
존 안이면 밴드가 진입 · 존 아래면 진입 없음). 따라서:

- "OB 내부 체결"(규칙 2) → OB 윗경계 > 진입가 → **연장 가능**.
- "근단 체결"(규칙 1, 진입가=OB 상단) → OB 윗경계=진입가 → `max`가 자동으로 **1.5R을 준다**.

즉 사용자 원문의 "내부체결만 적용"과 "전체 적용"은 **같은 결과**다(`max`가 게이트를 수행).
회귀 테스트가 이 동치를 고정한다(`test_proximal_fill_gives_exactly_the_floor`).

## 1. 방법 — 새 파이프라인 금지, `take_profit_override` 재사용

WAN-143 §0이 봉내 라이브 밴드(WAN-132)에 배선한 `take_profit_override`(목표가 하나)로
`max(1.5R, OB윗경계)`를 표현한다. floor(1.5R)는 현행 규칙(`_resolve_take_profit`)을 그대로
불러 계산하므로, OB 경계가 연장을 못 할 때 팔 B의 목표는 팔 A와 **정확히 같아진다**(지어낸
값이 아니라 현행과 비트 동일). **엔진은 건드리지 않았다** — 리포트 모듈이 후보를 직접 빌드하고
(`build_zone_limit_candidates`) 따뜻한 구간 필터(`trigger_time ≥ 평가경계`)는
`run_zone_limit_backtest_verbose`의 내부 로직을 그대로 복제한다.

| | 값 |
| -- | -- |
| 팔 A | `fixed_1.5r` — 현행 고정 1.5R(`take_profit_override=None` = 오늘의 채택 기본값) |
| 팔 B | `ob_extend` — `max(진입가+1.5R, OB 윗경계)` |
| 좌표 | 9종목 × 못 박은 6년(2020-09-15~2026-07-22) × 15m·1h·4h |
| 구간 | `full`·`is`·**`oos_warm`(따뜻, 주 수치)**·`oos`(차가움, 스트레스) — WAN-166 정본 |
| 렌즈 | `baseline`(판정) + `pen_5bp`(체결 보수화 병기) |
| 엔진 | 오늘의 채택 기본값(오프셋 2bp · `intrabar_live` · `unconditional` · 롱 온리 · 분리 존 · 필터 1.28) — **핀 없음** |

**검산(동작으로 고정)**:
- override=None 팔이 표준 CLI 경로(`harness.run_once` = `backtest.run --oos-warm`)와 구간마다
  **비트 단위로 같다**(실데이터 회귀 테스트) — 연장 훅을 얹어도 기본 실행이 조용히 달라지지
  않았음의 직접 증거.
- 익절은 청산만 바꾸므로 같은 (구간, 렌즈)의 두 팔은 **체결 셋업 집합이 비트 단위로 같다**
  (어긋나면 `AssertionError`).

## 2. 판정 — (a) 연장이 이기지만 **마진이 미미하다**(위험의 모양만 바꾼다)

**두 작업 TF(4h·1h) 모두 세 지표(수익·수익/MDD·mean_net_r)에서 연장이 이긴다 — 그러나 폭이
극히 작고, 위험조정으로는 사실상 제자리다.** 공식 렌즈(`baseline`) OOS(따뜻) 심볼평균:

| TF | fixed → extend total_return | 수익/MDD | mean_net_r | 유효심볼 |
| -- | -- | -- | -- | -- |
| 4h | +8.37% → +8.76% (Δ**+0.39%p**) | 2.53 → 2.71 | 0.327 → 0.363 | 7 |
| 1h | +18.39% → +18.69% (Δ**+0.30%p**) | 3.15 → **3.15** | 0.217 → 0.226 | 9 |

`pen_5bp`(관통 요구)에서도 부호는 유지된다(4h +7.91%→+8.07% · 1h +15.42%→+15.74%) — WAN-88식
"체결 가정에 전멸"이 아니다. 연장 목표가 멀어도 그 이득이 마진 체결에 특별히 더 기대지 않는다
(두 팔의 체결 셋업이 같아, 렌즈는 두 팔을 대칭으로 깎는다).

## 3. 무엇이 움직이나 — 승자 이익 ↑ · 승률 ↓(소폭) · 홀드 불변

공식 렌즈 OOS(따뜻) A→B 변화:

| TF | 승자 net R | 승률 | 홀드(봉) | 거래 수 | 청산: 익절/손절 |
| -- | -- | -- | -- | -- | -- |
| 4h | 1.423 → 1.511 (+0.088) | 56.04% → 55.47% (−0.57%p) | 2.1 → 2.1 | 181 = 181 | 55.8/44.2 → 55.2/44.8 |
| 1h | 1.351 → 1.381 (+0.031) | 54.66% → 54.41% (−0.25%p) | 1.6 → 1.6 | 동일 | 54.8/45.2 → 54.5/45.5 |

교과서적 교환이다 — 연장이 **승자 R을 조금 키우는 대신 승률을 조금 깎는다**. 두 효과가 거의
상쇄돼 순 이득이 +0.3%p대에 그친다. 📌 **홀드·거래 수가 사실상 불변인 것이 핵심 관찰**이다:
진입가가 대부분 OB 윗경계(근단)라 `max`가 floor(1.5R)를 돌려주므로 **연장이 실제로 발동하는
셋업이 소수**다. 그래서 슬롯 잠금 우려(이슈 §함정)는 이 규칙에서 현실화되지 않는다(EOD=0%,
거래 수 차이 0%). 못 닿은 거래는 EOD로 남지 않고 **손절로 끝난다**(연장 팔 손절률이 미세하게
높다).

## 4. 편중·심볼 — 소수 종목이 만들고, 한 종목은 오히려 손해

- **4h**: 이득은 **DOGE**(+7.09%→+9.99%, net_r 0.401→**0.709**)·LTC(+8.63%→+9.69%)·BTC·SOL의
  소폭에서 오고, **XRP는 오히려 나빠진다**(+0.06%→**−1.35%**, 승률 44%→40%). BNB·ETH·LINK·TRX는
  **완전히 동일**(연장 미발동 = 전부 근단 체결). 즉 연장은 "가끔 OB가 크게 벌어진 셋업"에서만
  작동하고, 그런 셋업의 방향이 종목마다 갈린다.
- **1h**: leave-one-out에서 어느 종목을 빼도 +13~20%로 **ETH 편중이 아니다**(ETH 제외가
  +13.54%로 최저 = ETH가 양(+)이지만 지배적이지 않다). 두 팔의 LOO 격차는 전 구간에서 +0.3%p대로
  균일하다.

## 5. 15m — 생성 중(별도 성능 병목)

15m 6년 격자는 봉내 라이브 밴드의 **밴드 시딩 O(N×M) 비용**(엔진 성능 병목 — WAN-204 범위
밖의 별도 이슈)으로 심볼당 ~25–30분, 총 ~4시간이 걸려 이 판에는 **아직 포함되지 않았다**.
모듈은 15m을 완전히 지원하며 아래 한 줄로 같은 CSV에 병합된다:

```
uv run python -m backtest.wan204_ob_extension_tp --tf 15m --append
```

⚠️ 4h·1h의 패턴(마진 미미·위험의 모양만)은 두 작업 TF에서 **일관**되므로, **결론(현행 유지)은
15m을 기다리지 않아도 성립**한다 — 15m 수치는 표를 채우지만 판정을 바꿀 여지가 작다.

## 6. 결론 — 현행(고정 1.5R) 유지, 채택 권고 없음

판정 기계는 (a)를 찍지만 **채택 권고가 아니다**:

- 마진이 +0.3%p대로 미미하고 **위험조정(수익/MDD)으로는 제자리**다 — 익절 자는 알파가 아니라
  **위험의 모양**만 바꾼다는 WAN-90 결론의 재확인이다.
- 전부 `baseline`(낙관 체결) 위 값이라 상한이다.
- 이득이 소수 종목(DOGE 등)에 몰리고 한 종목(XRP 4h)은 손해다 — 자유 파라미터를 하나 늘려
  앞구간에 맞추는 자리(WAN-108/143/155가 경계한 지점).
- **「엣지 없음」(WAN-84/88/111/114/124/151)은 불변** — 이 이슈는 익절 자 변경이지 진입 신호
  검정이 아니다.

**기본값·토대 불변**(`take_profit_r=1.5` · `take_profit_mode="fixed_r"` 유지 · 실거래 보류
`ALPHABLOCK_LIVE_TRADING=false`). 연장 규칙 채택은 **명시적 재-베이스라인이자 사용자 결정**이다
(개발자 임의 착수 금지). 사용자가 경고를 알고도 원하면 선행: 15m 완주 · 15m 관통 축(`pen_5bp`)
· 틱·호가 체결(WAN-98).
