# WAN-350: 「엣지 없음」을 오늘 좌표 · 가장 보수적인 체결 가정 위에서 다시 묻는다

> 📌 **사용자 지시 2026-08-21**: *"그걸 돌려보자. 나는 그 엣지없다는 말을 어떻게든 해소해야겠어."*

- 산출물: `backtest/reports/wan350_conservative_null.csv` ·
  `backtest/reports/wan350_conservative_null_loo.csv` · `backtest/reports/wan350_verify.csv` ·
  `backtest/reports/wan350_conservative_null_summary.md`
- 재현: 모듈 `backtest/wan350_conservative_null.py` docstring §재현
- **측정 전용** — `ConfluenceParams()`·`LeverageBookParams()` 기본값 불변 · 보수 팔은 전부
  옵트인 · 실거래 보류 유지(`ALPHABLOCK_LIVE_TRADING=false`)

## 0. 왜 이 칸이 비어 있었나

[WAN-346](wan346.md)이 채택 북 `oos_warm`에서 두 설명을 **실측으로 죽였다**:

| 용의자 | 상태 |
| -- | -- |
| **베타(강세장)** | **죽음** — 같은 창 12종목 buy&hold 평균 −6.6% · 중앙값 −26.6%인데 롱 온리로 +854%(복리 끔) |
| **복리 착시** | **죽음** — 사이징을 초기 자본에 못 박아도 +854%(CAGR 219%) · 거래당 net R 0.1985 → 0.1952 |

남은 유력 용의자인 **체결 낙관**도 같은 이슈의 팔 D가 쟀다(거래당 net R 0.1985 → 0.1089 =
**절반이 되지만 부호는 남는다**). 그런데 **팔 D가 버텨도 「엣지 있음」이 되지 않는다** —
이 저장소의 「엣지 없음」(WAN-84/88/111/114/124/151/201/248)이 실제로 말한 것은
*"같은 존에 **무작위 시각**으로 진입해도 비슷하게 나온다"*이고, **그 널은 오늘 좌표의 보수
가정 위에서 돌린 적이 없다.** 비어 있던 칸은 정확히 하나였다.

## 1. 무엇을 재는가

- **널 = 타이밍 축**: 같은 오더블록 유니버스 · 같은 거래 수 · 같은 방향 · 같은 시각대
  버킷에서 **어느 셋업이 체결되는지만** 무작위화한다(WAN-70 매칭 널). 묻는 것은
  *"우리 규칙의 진입 **타이밍**이 우연 대비 값을 더하는가"* 하나다.
- **무력화 축 = 볼린저**(`deviation_filter=None`). 🚨 **RSI 게이트 축은 쓸 수 없다** —
  게이트가 없는 오늘 엔진에서는 풀 == 실제가 되어 널이 **자기 자신을 검정**한다
  (WAN-124 발견 · `run_random_control_b_segment`가 `ValueError`로 거부한다).
- **팔**은 WAN-346 보수 축 2×2의 두 모서리다:

| 팔 | 렌즈 | 같은 분 익절 | 뜻 |
| -- | -- | -- | -- |
| `A` | `baseline` | 허용 | 채택 엔진 그대로 = 기준선 |
| `D` | `pen_5bp` | **금지** | 가장 보수적 — 두 축을 쌓음 |

  두 축은 **직교한다**: 가로 `pen_5bp`는 *「주문이 채워지느냐」*(큐 우선순위, WAN-96/124),
  세로 `no_same_step_tp`는 *「채워진 뒤 그 1분 안의 순서」*(WAN-336).
- **좌표**는 채택 그대로 — 12종목 × 15m·1h·2h·4h × 못 박은 6년(2020-09-15~2026-07-22) ·
  존폭 필터 1.28 · **핀이 하나도 없다**(WAN-305).
- **자**는 옛 널 계열과 **같은 값**이라야 「판정이 바뀌었다」와 「자를 바꿨다」가 갈린다 —
  `MIN_TRADES_FOR_VERDICT=20` · `ALPHA=0.05` · `BOOTSTRAP_ITERATIONS=200` ·
  `BOOTSTRAP_SEED=124`. 상수를 새로 쓰지 않고 `wan151`에서 **물려받는다**(테스트가 고정).
- **구간**은 따뜻한 연속 규약(WAN-166) — `oos_warm`이 주 수치, `full`이 기준선.

## 2. §0 엔진 — 보수 축을 **양쪽에** 거는 것이 이 이슈의 핵심 배선

널 기계(`wan70_random_control_b`)에 옵트인 두 축을 넣었다. **둘 다 끄면 엔진이 비트 단위로
예전과 같다**(옛 널 계열 CSV 재현 — §5 검산이 값으로 증명한다).

- **`no_same_step_tp`**(WAN-336 팔) — 실제 팔과 무력화 풀 **양쪽** 후보 생성에 똑같이 건다.
- **`eval_from_ms`**(WAN-166) — 탭(`trigger_time`) 시각으로 자른다. 북·`wan206`과 같은 규약이다.
- **체결 렌즈는 새 인자가 없다** — `ConfluenceParams`의 `fill_penetration_bps`에 실려 있어
  풀이 실제에서 파생되는 한 **자동으로 같은 렌즈**를 쓴다.

🚨 **한쪽에만 걸면 p값이 규칙이 아니라 「가정 차이」를 잰다.** 실제만 보수화하고 널은
낙관으로 두면 우리 규칙이 부당하게 불리해지고, 반대면 부당하게 유리해진다. 그래서 두 생성을
`_build_both_pools` **한 함수**에 나란히 묶었다 — 호출이 떨어져 있으면 다음에 축이 하나
더 생길 때 한쪽에만 붙는다(WAN-345가 래더에서 겪은 실패의 이 축 판).

📌 **후보 생성을 함수 밖으로 뺐다** — `run_random_control_b_evals`가 창을 한 번만 태우고
`full`·`oos_warm`을 함께 낸다. 통계·시드·표본추출은 `_null_from_candidates` **한 곳**에만
있어 두 진입점이 갈라질 수 없다. 15m 한 셀의 후보 생성이 **220초**(실측: 실제 110.1s +
풀 110.5s)라 이 공유가 격자를 감당 가능하게 만든다.

## 3. 🚨 재진입은 이 널에 없다 — 알고 뺀 것이고, 그 이유가 검산이다

채택 북은 재진입 ON(band, WAN-273)인데 **이 표의 두 팔은 재진입을 돌지 않는다.** 원칙
(WAN-305 「측정은 채택 규칙 위에서」)에 어긋나 보이지만 매칭 널에서는 그럴 수 없다:

1. **널이 구조적으로 표현하지 못한다.** 매칭 널은 *미리 만든 풀에서 실제와 같은 개수를
   뽑는* 방식인데, 재진입 후보는 **부모 거래가 익절로 청산돼야** 생긴다. 즉 개수 자체가
   표본에 의존해 「같은 개수를 맞춘다」는 널의 정의가 성립하지 않는다.
2. **비용이 200배로 는다.** 부트스트랩이 싼 이유는 셋업당 서브스텝 시뮬레이션을 정확히
   1회만 하기 때문인데(WAN-70 §성능), 재진입은 표본마다 새로 시뮬레이션해야 한다.
3. **검산이 깨진다.** §5의 대조 상대(`wan176_null.csv`·`wan201_matched_null.csv`)가 전부
   재진입-off 계열이다. 재진입을 넣으면 「판정이 바뀌었다」와 「축을 하나 더 움직였다」를
   가를 수 없다.

**재진입이 들어갈 자리는 북 널이다**(이슈가 이미 다음 단계로 지목 — 북은 배치가 싸다).
그래서 이 표는 이슈 본문대로 **탐색·귀속**이고 채택 근거가 아니다(WAN-341).

## 4. 결과

### 4-1. 헤드라인 — 보수화는 유의를 **깎되 지우지 않는다** (완료기준 2)

| 구간 | 팔 A(채택 엔진) | 팔 D(가장 보수적) | 잔존 |
| -- | --: | --: | --: |
| `full` | **39/48** | **33/48** | 85% |
| **`oos_warm`(주 수치)** | **22/46** | **17/46** | **77%** |

**WAN-346과 같은 모양이다** — 그쪽은 거래당 실력이 0.199R → 0.109R(55%)로 **절반이 되지만
부호는 남았고**, 이쪽은 유의 셀이 77% 남는다. 두 표가 서로 다른 자로 같은 말을 한다:
**체결 낙관을 걷어내면 크기는 줄지만 결론은 안 뒤집힌다.**

⚠️ **WAN-124의 붕괴와 같은 부류로 인용 금지** — 그때는 `baseline` 유의 4셀이 `pen_5bp` 한
번에 **전멸**했다(WAN-88). 이번엔 **22 → 17**이다.

### 4-2. TF 기울기 — 신호는 15m에 산다 (완료기준 1)

`oos_warm` 유의/유효:

| TF | 팔 A | 팔 D | A→D에서 유의를 잃는 종목 |
| -- | --: | --: | -- |
| **15m** | **11/12** | **9/12** | BTC · LTC |
| 1h | 6/12 | 5/12 | XRP · ADA (SOL은 오히려 얻음) |
| 2h | 4/12 | 2/12 | BNB · BCH |
| 4h | 1/10 | 1/10 | ETH (XRP는 얻음) |

TF가 길수록 유의가 줄고 4h는 표본 게이트에 두 셀이 걸린다(심볼당 23거래). **15m이 채택 북
거래의 66%를 차지한다는 사실**(WAN-312)과 겹쳐 읽으면, 이 표의 무게는 15m 행에 있다.

🚨 **팔 D 15m에서 BTC가 유의하지 않다**(p=0.145 · 실제 **−1.22%**). 가장 크고 유동성이 높은
종목이 보수 가정에서 먼저 떨어진다 — 「모든 종목에서 통한다」로 읽지 말 것.

### 4-3. 🚨 15m OOS 강세는 **새 발견이 아니다** — 새로운 것은 「보수화를 견딘다」이다

옛 기록(`wan176_null.csv` · 차가운 절단 · 9종목 · 필터 켜짐)을 같은 자로 세면 이렇다:

| | IS | OOS |
| -- | --: | --: |
| 15m | 9/9 | **7/9** |
| 1h | 7/9 | 3/9 |

**15m OOS는 그때 이미 7/9였다.** CLAUDE.md·WAN-201이 이 계열을 *"유의는 상승장 IS에 몰리고
OOS에서 급감"*이라 요약해 왔는데, 그 문장은 **1h·4h에서 참이고 15m에서는 약하다**(9/9 → 7/9).
이 표의 TF 기울기가 그 구조를 그대로 재현한다.

📌 **그래서 이 이슈가 실제로 채운 칸은 「15m이 세다」가 아니라 이것이다**: 그 강세가
**(a) 오늘 좌표(12종목·4TF·따뜻한 OOS)에서도** · **(b) 가장 보수적인 체결 가정에서도** ·
**(c) 한 종목에 기대지 않고** 남는가. 답은 **셋 다 예**다.

### 4-4. 편중이 아니다 (완료기준 3)

`oos_warm` leave-one-out — 종목을 하나씩 빼도 유의 셀이 남는다:

| 제외 | A | D | | 제외 | A | D |
| -- | --: | --: | -- | -- | --: | --: |
| (없음) | 22/46 | 17/46 | | DOT | 21/42 | 16/42 |
| ADA | 19/42 | 15/42 | | **ETH** | 19/42 | 15/42 |
| BCH | 19/42 | 15/42 | | LINK | 20/43 | 15/43 |
| BNB | 19/42 | 15/42 | | LTC | 21/42 | 17/42 |
| BTC | 21/43 | 17/43 | | SOL | 20/42 | 14/42 |
| DOGE | 21/42 | 16/42 | | TRX | 22/42 | 17/42 |
| | | | | XRP | 20/42 | 15/42 |

**ETH를 빼도 19/42 · 15/42다.** WAN-111 이래 이 저장소의 플러스가 거의 매번 ETH가 만든
것이었던 것과 **다르다**(WAN-142/152/203과 같은 부류의 드문 예외). 최악은 −SOL(팔 D 14/42).

⚠️ **per-cell 널이라 LOO가 「재집계」다** — 북처럼 지갑을 다시 배치하지 않으므로 「그 종목이
빠지면 다른 칸의 자본이 남는다」 같은 효과는 여기에 **없다**(WAN-316).

### 4-5. 부수 관찰 — 무작위 팔은 15m 보수 가정에서 **돈을 잃는다**

팔 D 15m `oos_warm`에서 **무작위 팔의 심볼평균이 +0.87%**인데(12셀 중 **7셀이 음수**) 실제
팔은 **+21.44%**(12셀 중 **11셀이 양수**)다. 같은 존·같은 거래 수·같은 방향·같은 시각대에
들어가되 **타이밍만 무작위로 바꾸면 수익이 사라진다**.

📌 **그리고 이 창은 하락장이다** — 같은 15m OOS 창의 buy&hold가 **12종목 중 8종목 음수 ·
중앙값 −25.5%**(DOT −82.5% · SOL −51.8% · ADA −50.3%). 롱 온리로 플러스가 나오므로
**베타 설명은 여기서도 죽는다**(WAN-346 §5-5의 이 축 재확인).

⚠️ **그래도 「엣지 있음」으로 인용 금지** — §6의 경고가 전부 그대로다. 특히 이 표가 이긴
대상은 **「존 근단가에 무작위 시각으로 들어간 팔」**이지 시장이 아니고, **per-cell이라 채택
근거가 아니다**(WAN-341 — 승격은 북 널이고 그게 다음 단계다).

### 4-6. 따뜻한 규약에 기대고 있지 않다 (검산이 덤으로 준 대조)

「따뜻한 OOS는 존 재고를 물려받으니 유리한 것 아닌가」가 이 표에 걸 수 있는 가장 자연스러운
반론이다. 검산이 낸 차가운 절단 행(팔 A · 1h · 9종목)과 이 격자의 따뜻한 행을 **같은 종목·
같은 TF·같은 팔**로 맞춰 세면 차이가 **1셀**이다:

| TF (9종목 · 팔 A · OOS) | 차가운 절단 | 따뜻한 연속 |
| -- | --: | --: |
| 15m | 7/9 | **8/9** |
| 1h | 3/9 | **4/9** |

📌 **규약을 바꿔도 판정이 안 흔들린다.** 두 방식은 다른 질문에 답하지만(WAN-166), 이 축에서는
답이 사실상 같다. ⚠️ 단 이건 **팔 A · 9종목 · 두 TF**에서만 확인한 것이고, 팔 D의 차가운 판은
안 쟀다(구간마다 재탐지라 후보를 공유할 수 없어 비용이 두 배 — §7).

## 5. 검산 (완료기준 4)

노브를 **끈** 팔 A가 옛 널 계열을 재현하는지를 값으로 확인한다. 이것이 통과해야 §4의
「팔 D에서 판정이 이렇게 됐다」를 **가정의 몫**으로 읽을 수 있다 — 안 통과하면 §2의
리팩터가 숫자를 움직였다는 뜻이라 표 전체가 무효다.

| 검산 | 대조 상대 | 무엇을 증명하나 |
| -- | -- | -- |
| `armA-filter-on-vs-wan176` | `wan176_null.csv` | 필터 켜짐(1.28) × 9종목 × 6년 1h 롱 축 |
| `armA-filter-off-vs-wan201` | `wan201_matched_null.csv` | 필터 꺼짐 × 같은 좌표 |

🚨 **`rows_compared == 0`을 일치로 접지 않는다** — 키가 어긋나면 비교할 것이 없어 「차이 0」이
나오는데 그건 재현이 아니라 **대조 실패**다(WAN-333이 이름 붙인 부류). 코드가 **일치 · 잡음 ·
불일치**를 다르게 찍고 회귀 테스트가 세 갈래를 동작으로 고정한다.

🚨 **검산은 DOGE·LINK·LTC의 펀딩을 비운다 — 데이터가 그 뒤 바뀌었기 때문이다.** wan176·wan201이
돌 때 이 세 종목은 `funding_rate` 테이블에 **0행**이었고, [WAN-292](../../docs/decisions/wan292.md)
백필(2026-08-12) 이후엔 실데이터가 있어 **같은 코드·같은 좌표를 줘도 그 CSV가 안 나온다**(거래
집합은 비트 동일한데 펀딩 비용만 달라진다). WAN-312가 같은 자리에서 겪었고 「핀은 파라미터를
고정하지 **데이터 상태**를 고정하지 못한다」로 기록했다. ⚠️ 그 복원은 **검산 전용**이고
§4 격자에는 쓰지 않는다(오늘 좌표는 실데이터로 돈다).

📌 **테스트가 얹는 검산 3종(실데이터)** — CSV가 아니라 **동작**으로 건다:

1. 널의 「실제」 다리 ≡ `harness.run_once`(= 인자 없는 `backtest.run`의 per-cell 경로)의
   총수익률·거래 수. 어긋나면 p값의 분자가 우리가 실제로 매매하는 엔진의 것이 아니게 된다.
2. `no_same_step_tp`를 켜면 후보 층 카운터(`ZoneLimitStats.same_step_take_profits`)가
   **실제로 0이 된다** — 인자를 넘기는 줄만 보는 테스트는 WAN-345가 겪은 실패를 또 통과시킨다.
3. 따뜻한 창이 실제·풀 **양쪽**에서 진부분집합이 된다(대칭이 깨지면 두 집합이 다른 기간을 본다).
