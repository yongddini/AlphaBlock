## 1. 설계 (이슈 그대로)

- 탭 봉 `N` · `1봉확인` = `N+1` 양봉 → `N+2` 시가 · `2봉확인` = `N+1`·`N+2` 양봉 → `N+3` 시가.
- 양봉 = 종가 ≥ 시가(동가 포함). 기회 한 번(첫 탭만 · 창을 넘으면 존 종료).
- 갈래(팔마다 `K`): (D) 기준 체결 ≥ 진입 시각 → (C) 익절 끈 판 청산 < `K` 마감 또는 봉 결측 →
  (A)/(B) 조건 충족/미충족. 이 순서로 배타 분류한다.
- 판정 관문(순서대로): 표본(각 ≥ 100) → 밀림(중앙 ≥ 1.55) → 선별(|Δ| > 2σ Bonferroni 8점 =
  2.765σ · > 0.005R · 양수) → 폭락일 통제(최악 10일 제외 **그리고** WAN-410 버킷 안 가중 합의
  부호 유지). `verdict_for()`가 계산한다.

## 2. §0 탭↔체결 간격

0봉 81.7~88.2% · **3봉+ 9.0~14.8%**. 「0봉 압도적」이 아니라서 (D)를 따로 세고 넣은 판을
병기했다 — 판정은 두 판에서 같다(D 포함 판은 1R 배수가 더 크다: 1봉확인 1.63~1.77×).

## 3. ③ 둘째 봉의 교환비

`N+2`까지 살아 있고 `N+1` 양봉인 셋업을 `N+2` 색으로 쪼갠 `oos_warm` 선별 이득은
15m +0.48R · 1h +0.53R · 2h +0.53R · 4h +0.17R(σ 0.18)이고, 기하 비용(두 팔 (A) 1R 배수 중앙값
차)은 +0.31~+0.38×다. `N+2` 안에서 손절난 셋업(15m 92건 등)은 동어반복이라 뺐다.

## 4. 왜 선별력을 채택 근거로 읽으면 안 되나

1. **net R은 기준 팔(볼린저 지정가)의 결과**다 — 확인 팔의 손익이 아니다.
2. **선별과 밀림은 같은 사건이다** — 양봉은 가격이 올랐다는 뜻이고, 그 상승이 기준 거래를 익절에
   가깝게 만드는 동시에 확인 진입가를 밀어 올린다(WAN-383 §1 「한 사건의 두 얼굴」).
3. (A)의 **20~42%는 확인 진입 전에 기준 팔이 이미 1.5R을 챙겼다** — 확인 팔이 못 먹는 몫.
   그것을 양쪽에서 뺀 참고 Δ도 +0.37~+0.74R이지만, 1·2는 그대로 남는다.
4. WAN-383 §1이 같은 형태의 관측을 냈고 WAN-386이 실제로 늦게 사서 재자 손익으로 안 갚아졌다.
