# WAN-439 — 스토캐스틱 팔 위 「폭락 국면(BTC 24h ≤ −5%) 진입 크기 ×0.5」 정식 측정

> 재현: `uv run python -m backtest.wan439_crash_size_layer --jobs 4`(요약만: `--from-csv`).
> 표: `backtest/reports/wan439_crash_size_layer_summary.md` · `wan439_crash_size_layer.csv`.
> 🚨 **측정 전용** — 기본값·토대·페이퍼 규칙(WAN-435) 불변. 페이퍼 규칙 변경은 **사용자 결정**.
> 실거래 보류 유지(`ALPHABLOCK_LIVE_TRADING=false`).

## §1 판정 — B 통과

WAN-438 탐색(시험 설정 100개+ · 채택 근거 아님)이 고른 층 하나를 **숫자를 못 박고 한 번** 쟀다.

| 팔 | 크기 | 8.6년 | 창 밖 | 6년 앞 | 6년 뒤 |
|---|--:|---|---|---|---|
| A 페이퍼 규칙 그대로 | 1.62% | +222% · 연 14.6% | −26% | +128% | +91% |
| **B 폭락 ×0.5** | 2.89% | **+314% · 연 18.1%** | −27% | +165% | +113% |

(각자 미끄러짐 포함 8.6년 평가손 MDD 35%에 크기를 맞춤. 같은 크기의 손절가 체결: A +335% · 연 18.8% /
B +464% · 연 22.4%.)

* 조건 (1) 8.6년 연환산: B 18.07% > A 14.65% ✅
* 조건 (2) A 맞춤 크기(1.62%)에서 세 구간 수익/MDD 악화 없음: 창 밖 −0.73 vs −0.75 ✅ · 6년 앞
  +4.17 vs +4.04 ✅ · 6년 뒤 +4.97 vs +4.85 ✅
* **탐색 수치가 그대로 재현됐다**(탐색 +313% · 연 18.0% → 정식 +314% · 연 18.1%). 크게 좋아지지도
  나빠지지도 않았다 — 숫자를 바꾸지 않고 같은 −5% · ×0.5를 쟀기 때문이다.

## §2 🔁 판정 조건 하나를 철회했다 (사용자 지적 2026-09-29)

첫 실행은 조건 (2)를 **A 크기와 B 크기 둘 다**에서 보게 짰고, B 크기(2.89%)의 6년 뒤 한 칸
(B +5.996 vs A +6.390)에서 「불통과」가 났다. 그런데 **A를 2.89%로 돌리면 8.6년 낙폭이 57.3%** —
우리 한도(35%)를 한참 넘는, 실제로는 쓸 수 없는 설정이다. 그 A와의 비율로 B를 떨어뜨리는 것은 판정 자가
아니다. 이슈 원문(「같은 크기에서」)의 뜻은 A가 실제로 쓰는 크기에서 B가 해치는 구간이 없느냐이고,
그 조건은 전부 통과한다. **B 크기 비교는 요약에 「참고(판정 밖)」로 그대로 남긴다**(지우지 않는다).

⚠️ 이 철회는 결과를 본 뒤의 변경이다 — 그래서 여기 적는다. 다만 바뀐 것은 **개발자가 이슈 문구에 더한
해석**이지 이슈가 정한 숫자(−5% · ×0.5 · MDD 35% · 세 구간)가 아니다.

## §3 탐색이 놓친 채널은 없었다

층을 **채택 북 배치**에 넣은 판(정본)과 **복리 층에서만** 바꾼 판(탐색 방식)이 **거래 하나까지 같다**
(두 체결 방식 모두 1,300건 · 한쪽에만 있는 거래 0건). 이 팔은 손절폭 ≥ 4%에 손절 2배라 진입 하나의
명목이 작아 북 명목 상한(5배)에 걸리는 일이 없다 — 크기를 줄여 비워지는 자리가 쓰이지 않는다.
📌 **엔진 훅(`run_leverage_book(risk_scale=)`)은 그 채널을 실제로 표현한다** — 합성 테스트에서 명목
1배짜리 여섯 칸 중 첫 칸을 0.5로 줄이면 여섯째가 들어온다(복리 층만 바꾼 판은 5건).

## §4 C(투매 예외 · 대조 전용) — 불통과

8.6년은 연 19.8%로 B보다 높지만 **6년 뒤 구간에서 A 크기 수익/MDD가 A보다 나쁘다**(+3.16 vs +4.85)
— 탐색이 「투매 예외는 6년 뒤를 해친다」고 본 그대로다. 채택 후보가 아니다.

## §5 검산

* A 팔(층 없음) · 손절가 체결 · 거래당 2%가 공개 CSV와 **최대 차 0.00e+00** — 현물 창 밖 228건 ·
  −24.98% · MDD 36.00%(WAN-438) · 선물 6년 1,075건 · +678.51% · MDD 32.00%(WAN-436). 엔진을
  고치고 후보를 새로 만들었는데도 같은 숫자 = 훅을 안 켜면 아무것도 안 바뀐다는 직접 증거.
* 폭락 국면 판정은 **진입 분 이전에 확정된 1분봉만** 본다 — 테스트가 「진입 분부터 뒤를 반토막 내도
  값이 불변 · 직전 분을 바꾸면 변함」을 동작으로 고정한다. 선물 구간은 **선물** BTC, 현물 창 밖은
  **현물** BTC 1분봉이다.
* 폭락 국면 후보: 현물 249/467 · 선물 1,154/2,710 · 판정 불가(NaN) 0.

## §6 엔진 변경 (옵트인 · 안 주면 비트 동일)

* `leverage_book.run_leverage_book(risk_scale=)` — `(칸, 후보) → 배율`로 그 진입의 `risk_per_trade`만
  곱한다(명목 천장·북 상한 불변). `net R`은 배율과 무관. 0 이하·비유한 배율은 거부.
* `book_cli.iter_book_segments` · `wan424.place_segments`는 그대로 흘려보낸다.
* `wan436.place(size_layer=, layer_in_book=)` — 층 배율을 복리 크기와 북 배치에 함께 넣는다.
  규칙 넷의 예산 배율은 예전처럼 복리 층에서만(기준 팔 A가 WAN-436/438 숫자를 유지하도록).
* `wan436.mtm_path` — `simulate`의 1분 평가 경로를 꺼내 두 구간을 이어 붙인다(한 벌).
* ⚠️ 엔진 파일이 바뀌어 **후보 payload 캐시가 전 칸 미스**가 됐다(선물 279칸 · 현물 168칸 재생성,
  설계대로 — WAN-253). 첫 실행 약 70분, 캐시 적중 재실행 **445초**(`--jobs 4` · M1).

## §8 B + 15m — 세 자 모두 통과 (사용자 요청 2026-09-29)

재현: `uv run python -m backtest.wan439_b15m --jobs 3`(요약만 `--from-csv`) · 표
`backtest/reports/wan439_b15m_summary.md`. §1 경로(채택 북 · 인과 판정 · 검산)를 그대로 쓰고 TF에 15m만
더했다(선물 9TF → 10TF · 현물 8TF → 9TF). `9TF`는 `+15m` 후보에서 15m을 빼고 신호 수를 다시 센 판이다.

| 자 | 팔 | 크기 | 8.6년 |
|---|---|--:|---|
| ① 미끄러짐 · MDD 35% | A | 1.62% | +222% · 연 14.6% |
| | B | 2.89% | +314% · 연 18.1% |
| | **B + 15m** | 2.92% | **+443% · 연 21.9%** |
| ② 손절가 · MDD 30% | A | 1.63% | +339% · 연 18.9% |
| | B | 2.91% | +469% · 연 22.5% |
| | **B + 15m** | 2.92% | **+643% · 연 26.4%** |
| ③ 손절가 · MDD 35%(PR 뒤 추가 요청) | A | 1.94% | +457% · 연 22.2% |
| | B | 3.45% | +650% · 연 26.6% |
| | **B + 15m** | 3.46% | **+928% · 연 31.3%** |

* 판정(착수 전 고정 · §1과 같은 형태 — 비교 기준은 9TF의 맞춤 크기): 세 자 × 두 팔(A·B) 전부 **통과** —
  8.6년 연환산 개선 + 창 밖 · 6년 앞 · 6년 뒤 수익/MDD 악화 없음. 15m 후보 254건(현물 53 · 선물 201).
* 탐색 값(+442% · 연 22%)이 정식 경로에서 재현됐다.
* 검산: 9TF × A = 공개 CSV 0.00e+00 · 9TF × B = §1 B 크기·수익 0.00e+00(15m을 더해 만든 후보에서
  15m을 빼면 원래 팔로 돌아온다).
* ⚠️ 15m 칸 후보 재생성 비용: 선물 31칸 + 현물 20칸 약 80분(`--jobs 3` · M1 · 테스트 스위트와 경합) ·
  실행 전체 4,896초. WAN-430(15m은 뒷구간에 뺀다)과는 **자가 다르다**(그쪽은 몰림 규칙 없는 팔의 거래당
  net R) — 결론을 섞지 말 것.
* 페이퍼 규칙(WAN-435)에 B · 15m을 넣는 것은 **사용자 결정**이다.
* ⚠️ ③은 ①과 **같은 낙폭 숫자(35%)를 낙관적 체결로** 잰 자다 — 같은 3.46%로 손절을 그 1분 저가에 채우면
  8.6년 낙폭이 **40.7%**로 한도를 넘는다(①이 그 크기를 2.92%로 낮춘 이유). 실제 체결은 두 끝 사이다.
