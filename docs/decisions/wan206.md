# WAN-206: 존높이 기준 익절을 **오늘 엔진**에서 재측정 — 2팔 손익 격자

**성격** 측정 전용(기본값·토대 불변, `take_profit_r=1.5`·진입가 기준 1R **유지**, 실거래
보류 `ALPHABLOCK_LIVE_TRADING=false`) · WAN-143을 오늘 채택 좌표(필터 1.28 · 9종목 · 못 박은
6년)로 다시 돌린 것 · **WAN-143 모듈 재사용**(익절 오버라이드·산식 그대로 import, 새 파이프라인
없음).

**재현**

```
uv run python -m backtest.wan206_zone_height_tp_today --tf 4h
uv run python -m backtest.wan206_zone_height_tp_today --tf 1h --r-sweep --append
uv run python -m backtest.wan206_zone_height_tp_today --tf 15m --r-sweep --append
uv run python -m backtest.wan206_zone_height_tp_today --from-csv    # 요약만 재생성
uv run python -m backtest.wan206_zone_height_tp_today --checksum    # run_once 비트 일치
```

원본: `backtest/reports/wan206_zone_height_today.csv` ·
요약: `backtest/reports/wan206_zone_height_today_summary.md`

🗣️ **이름 규칙** — `A안`/`B안` 라벨 금지. **익절 축**: `entry_r`(익절-진입가기준, 현행 =
진입가→손절 거리 × 1.5R) vs `zone_height`(익절-존높이기준, 제안 = 존 높이 × 1.5R). 볼린저가
진입가를 존 안쪽으로 밀면 두 자가 갈린다(현행 1R은 쪼그라들고 존높이는 그대로).

## 1. 왜 다시 재는가 — WAN-143은 오늘 엔진이 아니다

[WAN-143](wan143.md)이 이 가설을 이미 쟀고 판정은 **(c) 두 작업 TF가 정반대**였다(15m 현행
승·1h 존높이 승, 단 1h 우위는 ETH를 빼면 소멸·IS에선 현행 승). 그런데 WAN-143(2026-07-20)
이후 채택 기본값이 **두 번** 바뀌었다:

* **존폭 필터 1.28 채택**([WAN-159](wan159.md), 07-21) — WAN-143은 필터가 **꺼진 채** 쟀다.
* **9종목 · 못 박은 6년 확장**([WAN-182](wan182.md), 07-23) — WAN-143은 **6종목 · 3년**이다.

즉 **지금 매매하는 엔진에서 존높이 익절을 잰 적이 없었다.** 필터가 이미 "좁은 존만"
남기므로(존폭 ÷ ATR ≤ 1.28) 존높이와 진입가→손절 거리의 간극이 예전과 다르게 움직일 수 있다.

⚠️ **WAN-143 표와 이 표의 셀을 직접 비교하지 말 것** — 창·유니버스·필터가 통째로 다르다
(6종목3년 필터끔 vs 9종목6년 필터1.28). "전 대비" 서술은 방향으로만 읽는다.

## 2. 무엇을 어떻게 쟀나

* **좌표**: 9종목 × 못 박은 6년(2020-09-15\~2026-07-22) × 15m·1h·4h × IS/oos_warm/oos.
* **엔진**: 채택 기본값 그대로 — 필터 1.28 · `intrabar_live` · `unconditional` · 오프셋 2bp ·
  `combine_obs=False`. **핀 없음**(`LEGACY_*`·`pin_*` 미사용, `OrderBlockParams()`가 곧 오늘
  기본값). WAN-143 모듈은 `LEGACY_OB_PARAMS`(병합 ON)를 썼으므로 그대로 재실행할 수 없어,
  WAN-206 모듈이 WAN-143의 오버라이드·산식만 import하고 좌표·엔진을 오늘 것으로 바꿨다.
* **가드**: 오늘 기본값 `min_stop_distance_fraction=0.003`으로 **고정**(축 아님 · 가드 변경은
  WAN-76/79 소관·재-베이스라인). WAN-143의 guard on/off 2×2는 열지 않았다 — 익절 축만 격리.
* **렌즈**: `baseline`(공식) **+** `pen_5bp`(병기). 존높이 익절은 목표가 멀어 슬롯을 더 오래
  잠그므로 체결 보수화가 핵심이라 이슈가 명시적으로 요구했다.
* **OOS**: [WAN-166](wan166.md) 정본 — `oos_warm`(따뜻한 연속, **주 수치**) + `oos`(차가운
  절단, 스트레스). 두 값의 차이가 강건성 신호다.
* **신규 3종목(DOGE·LINK·LTC) 펀딩 대리**: 이 창에서 펀딩 0행이라 BTC 시계열로 대체(WAN-180/
  wan95 `apply_funding_proxy`, 보수적 = 롱에게 가장 비싼 종목). `--no-funding-proxy`로 끈다.

**검산**: `entry_r` 팔(`take_profit_override=None`)이 `harness.run_once`와 **비트 단위로 일치**
(따뜻·차가움 양쪽, `--checksum` + 실데이터 게이트 테스트) → 존높이 팔의 델타가 배선 인공물이
아님이 보장된다. 익절만 바꾸므로 두 팔의 체결 셋업 집합이 같아야 한다는 불변도 격자가 동작으로
검산한다(어긋나면 `AssertionError`).

## 3. 판정 — 세 TF 모두 baseline에선 존높이 근소 우세(a), 그러나 채택 근거는 아니다

📌 **공식 렌즈(`baseline`) 따뜻 OOS(주 수치) 심볼평균 total_return**:

| TF | 현행(`entry_r`) | 존높이(`zone_height`) | Δ(따뜻) | Δ(차가움) | **Δ(`pen_5bp`)** | 수익/MDD | 편중 |
| -- | -- | -- | -- | -- | -- | -- | -- |
| 4h | +8.57% | +9.09% | **+0.52%p** | +0.24%p | +0.54%p (유지) | 2.67→2.69 | 아님 |
| 1h | +18.36% | +18.66% | **+0.30%p** | +0.53%p | +0.80%p (유지) | 3.14→3.13 | 아님 |
| 15m | +37.00% | +38.28% | **+1.28%p** | +1.34%p | **−0.30%p (뒤집힘)** | **6.16→5.87** | DOGE 의존 |

세 TF 모두 판정 문자는 **(a)**(존높이가 따뜻·차가움 둘 다에서 이긴다)지만, **채택 권고는
없다**. 근거 넷:

1. 🚨 **15m 우위는 낙관 렌즈의 산물이다 — `pen_5bp`에서 부호가 뒤집힌다**(+1.28%p → −0.30%p).
   이슈가 정확히 경고한 자리: 존높이는 목표가 멀어 슬롯을 더 오래 잠그고 마진 체결에 더
   기댄다. 4h·1h는 pen_5bp에서도 유지되지만 **15m은 안 된다** — 오늘 엔진에서 15m 존높이의
   우위는 "스치듯 닿은 체결"에 실려 있다(WAN-96/124의 15m 체결 민감성 재현).
2. **폭이 미미하다** — Δ가 +0.3\~+1.3%p 수준. 익절 자는 알파가 아니라 **위험의 모양만
   바꾼다**([WAN-90](wan90.md))는 원칙 그대로다.
3. **위험조정하면 무승부\~약간 손해** — 승률이 내려가고(존높이 4h −3.4%p · 1h −1.7%p · 15m
   −0.2%p) MDD가 올라, 수익/MDD는 세 TF 다 평평하거나(4h·1h) 오히려 나빠진다(15m 6.16→5.87).
   승률↓·크기↑ 교환(meanR은 오른다)이라 총수익은 근소하게 앞서지만 낙폭을 산 대가다.
4. **`take_profit_r=1.5`·진입가 기준 1R을 바꿀 이유가 없다** — 존높이로의 전환은 **명시적
   재-베이스라인이자 사용자 결정**이고, 이 표는 그 결정을 위한 오늘-엔진 근거일 뿐 채택 신호가
   아니다.

### 3-1. WAN-143 대비 무엇이 바뀌었나 (방향만 — 셀 직접 비교 금지)

* 📌 **15m 방향이 뒤집혔다** — WAN-143(6종목3년 필터끔)에선 **15m만 현행이 이겼는데**(존높이가
  진 유일한 TF), 오늘 엔진에선 15m도 baseline에서 존높이가 앞선다(+1.28%p). 단 위 (1)의 경고가
  붙는다(pen_5bp에서 소멸).
* 📌 **ETH 편중이 풀렸다** — WAN-143의 1h 우위는 ETH를 빼면 사라졌는데, 오늘 엔진에선 4h·1h가
  **leave-one-out 9/9 전 종목에서** 존높이 우세다(좁은 존만 남기는 필터 1.28이 편중을 푼 것으로
  보인다). ⚠️ **단 15m은 예외** — leave-one-out에서 DOGE(신규·대리 펀딩 종목)를 빼면 존높이가
  현행에 진다(−DOGE: 존높이 +32.18% vs 현행 +33.47%). 15m 우위는 DOGE 한 종목에 기댄다.

### 3-2. R 배수 스윕 (`zone_height`, baseline)

* **1h**: IS 최적 3.0R → **OOS 최적 1.5R**(정점). IS가 고른 3.0R이 OOS에서 무너진다(+13.88%) —
  **자(1R 정의)를 존높이로 바꿔도 1.5R이 OOS 정점으로 살아남는다**(WAN-90 진입가 축의 재현).
* **15m**: IS·OOS 둘 다 3.0R로 단조 상승(1.5R이 정점 아님, OOS 3.0R +47.54%). ⚠️ 단 이 곡선은
  전부 baseline 위 값이고, 15m 존높이 자체가 pen_5bp에서 뒤집히므로 "15m은 3.0R로 가라"로 읽지
  말 것 — 큰 R일수록 익절 도달이 드물어 마진 체결·큰 러너에 더 기댄다.
* **4h**: 스윕 안 돌림(비용, r=1.5만).

### 3-3. 표본 게이트 · 4h

* 4h는 따뜻 OOS 심볼당 ~24거래로 WAN-84 유효 기준(20)을 **평균으로는 통과**하나 얇다
  (BTC 15거래 등). 방향(존높이 근소 우세)은 1h·15m과 같다.
* TRX 15m은 79거래로 게이트를 통과(필터 1.28은 WAN-154의 분위 필터보다 후보를 덜 깎아
  붕괴하지 않는다, WAN-197과 정합).

## 4. 함정 / 기록

* 🚨 **"존높이가 낫다"·"15m에서 뒤집혀 이겼다"로 단독 인용 금지** — 15m 우위는 `pen_5bp`에서
  소멸하고 DOGE에 기댄다. 4h·1h 우위는 폭이 미미하고 위험조정 무승부다.
* **「엣지 없음」([WAN-84](wan84.md)/88/111/114/124/151/201)은 불변** — 이 표는 *익절 목표를
  어디에 둘까*를 물었을 뿐 *진입 규칙이 무작위와 구분되는가*(다른 질문)를 뒤집지 않는다.
* **전부 `baseline`(낙관 체결) 위 값** — 손익·체결률은 상한이고, 존높이는 목표가 멀어 그
  상한에 더 기댄다(pen_5bp가 그 크기를 보여준다). 틱·호가 해소는 WAN-98 소관(Canceled).
* **기본값·토대 불변** — `take_profit_r=1.5` · 진입가 기준 1R · 필터 1.28 · `intrabar_live` ·
  `unconditional` · 오프셋 2bp · `combine_obs=False` · 롱 온리. 존높이 전환은 사용자 결정 ·
  개발자 임의 착수 금지. 실거래 보류 유지.
