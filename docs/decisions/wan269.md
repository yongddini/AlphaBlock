# WAN-269 — 재진입을 채택 북에 켜되 진입가 = band(볼린저 재산정)로 (freeze→band 재실행)

**성격** 측정 전용(기본값·토대 불변 · `ConfluenceParams()`·`OrderBlockParams()` 불변 ·
채택 북 cap_only 5배 그대로 · `ALPHABLOCK_LIVE_TRADING=false` 유지). WAN-261/262가 「익절 후
존 내 재진입」을 채택 레버리지 북에 통째로 켜서 손익·MDD·위험을 쟀지만, 그 재진입 후보는
`_iter_reentries`의 **기본값** `entry_rule="freeze"`(첫 체결가 고정)로만 돌았다. WAN-267/268
격리 완전 분해는 진입가 3팔(freeze/zone/**band**)을 비교해 **band(재무장 순간 봉내 라이브
밴드 재산정)가 리더**라고 판정했다(격리 OOS baseline). 즉 「제일 나은 재진입 진입가(band)를
실제 채택 북에 통째로 켠 손익·MDD·위험」은 아직 없었다 — 이 이슈가 그 실측이다. 격리 상한
(WAN-267)은 자본 경합·슬롯·북 상한을 모델링하지 않으므로 북에 얹으면 이보다 줄어든다.

**재현**

```
uv run python -m backtest.wan269_reentry_book_band --tf 1h,2h,4h --jobs 6
uv run python -m backtest.wan269_reentry_book_band --tf 15m --append --jobs 6   # 15m 무거움(~37분/셀)
uv run python -m backtest.wan269_reentry_book_band --from-csv                    # 요약만 재생성
```

원자료: `backtest/reports/wan269_reentry_book_band_cells.csv`(칸별 개별 수익률) ·
`backtest/reports/wan269_reentry_book_band_grid.csv`(북 격자) · 요약:
`backtest/reports/wan269_reentry_book_band_summary.md`. 오늘 엔진(핀 없음) · 9종목 · 못 박은
6년 창(WAN-182) · 채택 북 cap_only 5배(WAN-213) · 렌즈 `baseline` 단독(WAN-128). **1h·2h·4h가
이 PR이고 15m은 `--append` 후속**이다(WAN-261→262, WAN-267→268과 같은 패턴 — 15m 셀당 ~37분).

## 0. 엔진 배선 (WAN-228 재무장 루프의 `entry_rule` 훅을 북 경로까지 잇기 · 옵트인 · freeze=비트 재현)

WAN-267이 `_iter_reentries`에 `entry_rule`(`"freeze"|"zone"|"band"`, 기본 `freeze`)를
배선했지만 그 훅은 **격리 분해**(`wan267`)에만 닿았고 북 경로(`reentry_candidates` →
`reentry_candidates_for_window` → `run_cells`)는 항상 freeze였다. 이 이슈가 그 인자를 북
경로 끝까지 잇는다:

* `reentry_candidates`(WAN-228) · `reentry_candidates_for_window`(WAN-169) · `_Task` ·
  `run_cells`에 `entry_rule` / `reentry_entry_rule`(기본 `"freeze"`)를 추가.
* **안 넘기면 freeze** → base 후보 생성은 규칙과 무관하고 재진입도 첫 체결가 고정이라
  **wan261/262 북 CSV가 비트 재현**된다(완료기준 2). 회귀 테스트가 라벨이 아니라 동작으로
  고정한다: `run_cells(reentry_entry_rule="freeze")` ≡ `run_cells()`의 base·재진입 후보 비트
  일치, band는 재진입 후보를 실제로 바꾸되 base는 안 바꾼다.
* band 팔은 볼린저 필터가 있어야 성립한다 — 필터가 없으면 재산정할 밴드가 없어 재진입을
  **아예 건너뛴다**(WAN-267 가드 그대로, 세 팔의 체결 집합이 달라진다).

세 팔은 payload 두 세트(freeze 재무장 · band 재무장)로 낸다 — base 후보는 규칙과 무관해 두
세트에서 비트 동일하므로 **off는 어느 세트로 계산해도 같고**(freeze 세트 사용), freeze·band는
각자 세트에서 base+재진입으로 낸다.

## 1. 판정 — band를 북에 얹으면 freeze 대비 전체 위험이 어떻게 되나 (판정: 사실상 무승부)

**band와 freeze의 위험 차이는 작다** — 격리에서 리더였던 band가 북에 얹히면 freeze 대비
뚜렷한 위험 우위로 이어지지 않는다. 주 수치(`all`·oos_warm):

| 팔 | 거래 | MDD | 최대 동시 리스크 | 청산 |
| -- | --: | --: | --: | --: |
| off | 1375 | 12.17% | 9.80% | 0 |
| freeze | 1743 | 14.89% | 11.36% | 0 |
| band | 1598 | 15.59% | 11.36% | 0 |

* **band−freeze**: MDD Δ**+0.70%p** · 최대 동시 리스크 Δ**−0.00%p** · 청산 Δ**+0**. `all`
  집계에서 band가 freeze보다 낙폭이 아주 조금 크되 동시 리스크·청산은 불변이다.
* **band는 freeze보다 거래가 적다**(1743 → 1598) — band 팔은 볼린저 규칙 3(밴드가 존
  반대편이면 진입 없음) 때문에 재무장 지정가를 재산정하며 일부 재진입을 **건너뛴다**(WAN-267
  가드). 격리에서 band가 이긴 것은 「닿은 거래의 질」이지 「더 많이 체결」이 아니다.
* **TF별로는 방향이 갈린다**(수익/MDD, oos_warm) — **1h·2h는 band가 freeze보다 낙폭을
  줄인다**(1h MDD 12.45% → 10.73% · 수익/MDD 34.16 → 40.83 · 2h 9.55% → 7.74% · 24.16 →
  28.77), **4h는 band가 진다**(MDD 동률 7.28%인데 수익/MDD 24.49 → 16.46). 하나의 규칙으로
  네 TF를 동시에 좋게 못 한다 — `all` 집계의 +0.70%p는 이 상쇄의 순합이다.
* **leave-one-out**: band 팔은 어느 종목을 빼도 강하게 플러스라 **특정 종목 편중이 아니다**
  (ETH·SOL 제외 시 총수익%가 가장 많이 줄지만 여전히 큰 플러스 — freeze와 같은 모양). ⚠️
  총수익%는 복리 착시라 방향만 읽는다.

**요지**: WAN-267 격리 분해의 「band가 리더」는 **북 전체 위험에서는 사실상 무승부로
희석된다** — 격리 상한(자본 경합·슬롯·북 상한 미모델링)이 북에 얹히면 줄어든다는 이 이슈의
전제가 실측으로 확인됐다. 채택 근거가 아니라 그 희석의 측정이다.

**검산(완료기준 2)**: wan269 `off`·`freeze` 팔이 기존 `wan261_reentry_book_grid.csv`의
`off`·`on` 팔과 **160행씩 최대 절대차 0.00e+00**(비트 일치) — `entry_rule` 배선이 기본
경로(freeze)를 건드리지 않았음을 실데이터로 못 박는다.

## 2. 성격 · 경고 (그대로 옮길 것)

* ⚠️ **총수익%는 복리 착시**(WAN-213) — 레버리지 북의 %는 수백~수천 거래 복리 값이라 실현
  수익이 아니다. 판단은 **MDD · 최대 동시 리스크 · 청산 건수**의 팔 간 차이(band−freeze가
  핵심, band−off는 재진입 없음 대비)다.
* ⚠️ 전부 `baseline`(닿으면 체결) 낙관 위 값이고 **band 재진입은 밴드가 체결이라 큐
  우선순위상 가장 안 될 체결에 기댄다** — 체결 보수화(pen_5bp)가 핵심이고 15m은 특히 못
  믿는다(격리에서 15m 잔존 48.7% vs 2h 80.9%, WAN-267). 비용·체결 보수화 병기는 WAN-264/265
  패턴 재사용(별도 축).
* ⚠️ **격리 값(WAN-267)과 셀 직접 비교 금지** — 격리는 1포지션·재진입만이고 이 표는 북 공유
  자본이다. 격리 상한이 북에서 얼마나 줄어드는지를 보는 표다.
* 「엣지 없음」(WAN-84/88/111/114/124/151/201/248)과 **다른 질문**이라 뒤집는 게 아니다 — 이
  축은 "이미 하기로 한 재진입 중 어느 진입가가 나은가"이지 "진입 규칙이 무작위와 구분되는가"가
  아니다. 유의여도 채택 근거 아님.
* **채택(재진입 기본값화 · band 진입가)은 재-베이스라인 = 사용자 결정 · 개발자 임의 착수
  금지.** 라이브는 러너 배선(WAN-45)·큐 우선순위(WAN-98 Canceled) 선행. **기본값·토대 불변**
  (측정 전용 · `ALPHABLOCK_LIVE_TRADING=false` 유지).
