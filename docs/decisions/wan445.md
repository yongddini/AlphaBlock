# WAN-445 — 스토캐스틱 팔 크기 = 손절폭 비례(명목 고정)

> 재현: `uv run python -m backtest.wan442_momentum_rotation --part markets --jobs 4`(시장 피클이 없으면) →
> `uv run python -m backtest.wan445_width_sizing --part run`. 표:
> `backtest/reports/wan445_width_sizing_summary.md` · 행 `wan445_width_sizing.csv` · 판별
> `wan445_width_picks.csv`. 🚨 **측정 전용** — 기본값·토대·페이퍼 규칙 불변 · 실거래 보류 유지.

## §0 착수 전에 못 박은 것 (측정 전에 커밋 · 결과를 보고 옮기지 않는다)

* **왜**: WAN-444(거래대금 상위 31종목)는 근소하게 불통과였다. 종목 선택과 **독립인 축**인 크기 규칙이
  남은 후보다. WAN-424 §8 탐색에서 「손절폭에 비례한 크기」(거래당 리스크 ∝ 손절폭 = 거래당 명목 고정)는
  26개 설정 중 유일하게 앞구간·뒷구간 모두에서 수익/MDD를 올렸다(24팔 중앙값 앞 1.27배 · 뒤 1.14배). 다만
  스크래치 · 옛 좌표였고 B + 15m · 8.6년 · 채택 북 경로에서는 안 쟀다.
* **규칙(하나)**: 거래 크기 배율 = 기존 층(B 폭락 ×0.5) × `d / D`.
  * `d` = 진입가 대비 **원래** 손절 거리(손절 2배 규칙은 모든 거래에 같은 상수배라 무관).
  * `D` = **앞구간 진입 전부의 `d` 평균**(현물 창 밖 전부 + 선물 대표 경계 2024-08-08 이전). 한 상수이고
    모든 판에 공통이며 뒷구간 정보를 안 쓴다.
  * 층은 채택 북 배치에도 들어간다(B와 같은 `in_book=True`). 크기는 기존처럼 미끄러짐 MDD 35%에 맞춘다
    (`D`의 스케일은 맞춤이 흡수한다).
* **장비 = WAN-442/444 그대로**: 같은 시장 피클 · 같은 평가(`wan442.evaluate`) · 같은 앞/뒤 · **같은 무작위
  교체 20회**(시드 442 + 판 번호) · 「새 진입만 막기」 처리 · WAN-443 이후 정렬 · 핀 없음.
* **판(같은 판에서 균일 크기 vs 손절폭 비례)**: 무작위 교체 20회 · 손으로 고른 31종목 고정 ·
  (참고) 거래대금 상위 31종목.
* **판정(둘 다 만족해야 통과)**:
  1. 무작위 20회 중 **앞구간 연환산이 좋아진 판 ≥ 15** 이고 **뒷구간 수익/MDD(앞구간 맞춤 크기)가 좋아진
     판 ≥ 15**(각각 부호 검정 한쪽 p ≈ 0.021 · 같으면 좋아진 것으로 세지 않는다).
  2. 손으로 고른 31종목에서 앞·뒤 둘 다 좋아짐.
* **검산**: 균일 판(무작위 20회 + 31종목)이 WAN-442 공개 CSV와 같은 값(텍스트 왕복 허용 오차 1e-12 · 거래 수
  정수 일치).
* **다음 행동(미리 정함)**: 통과 → 페이퍼 크기 규칙 후보로 사용자에게 올린다(채택은 사용자 결정).
  불통과 → 크기는 균일 유지로 기록. ①(WAN-444)이 불통과라 ③(둘 합)은 재지 않는다.

## §1 판정 — 불통과 · 앞구간은 20/20 좋아지는데 뒷구간은 12/20(동전 던지기)

| 조건 | 값 | 기준 | 결과 |
|---|---|---|---|
| (1) 무작위 20회 — 앞구간 연환산 좋아진 판 | **20개** | ≥ 15 | ✅ |
| (1) 무작위 20회 — 뒷구간 수익/MDD 좋아진 판 | **12개** | ≥ 15 | ❌ |
| (2) 손으로 고른 31종목 | 앞 +14.6% → +16.2% · 뒤 +6.78 → +7.72 | 둘 다 개선 | ✅ |

기준을 결과 뒤에 옮기지 않으므로 **불통과로 기록하고 크기는 균일을 유지한다.**

## §2 읽는 법

* **앞구간 효과는 강하다** — 무작위 20회 전부 좋아졌다(중앙 +11.3% → +15.0%). 부호 검정으로 우연일 확률이
  약 100만분의 1이다. WAN-424 §8의 「앞 1.27배」와 같은 방향이다.
* **뒷구간은 갈린다** — 12개 좋아지고 8개 나빠졌다(중앙 +4.01 → +4.45). 좋아지는 폭은 작지 않지만 나빠지는 판도
  적지 않다(#03 +5.47 → +4.58 · #19 +3.13 → +2.53). 한쪽 구간에서만 강한 모양은 WAN-432(손절폭 하한)와 **반대
  방향**이다 — 그쪽은 뒷구간에만 있었고 이쪽은 앞구간에만 확실하다. 이 팔에서는 「넓은 손절에 더 건다」의
  값어치가 **장세에 따라 달라진다**고 읽는 것이 가장 정직하다.
* **31종목에서는 좋아지지만 폭이 작다** — 8.6년 맞춤 크기에서 연 +22.6% → **+23.3%**(+0.7%p). 25% 목표에는
  못 미친다. 뒷구간 MDD가 19.4% → 15.9%로 내려간 것이 가장 큰 변화다.
* **참고(거래대금 상위 31종목)**: 앞 +12.8% → +15.2% · 뒤 +6.24 → +8.09 · 8.6년 +18.5% → +21.0%. ③(두 규칙 합)은
  미리 정한 대로 판정하지 않는다 — 둘 다 따로 통과하지 못했다.
* **크기 배율의 모양**: `D` = 7.04% · 풀 전체 `d/D` 10%/50%/90% = 0.60 / 0.81 / 1.48 · 최대 9.55. 넓은 손절 소수에
  크게 건다. 명목은 거래마다 같아 복리 명목 한도(자본 × 5) 초과 진입은 0건이다.
