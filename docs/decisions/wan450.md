## §9 사용자 결정(2026-10-14) — 캐리는 운용하지 않는다

사용자 결정: *「개인적으로 펀딩비 받는 건 별로인 것 같다」* → 개발자 의견(지금 펀딩 수준에서 캐리 몫 연
+1.8%p는 빠진 위험 · 증거금 압박 · 운영 복잡도에 비해 작다)에 동의. **채택 구성은 「팔 + 추세추종」 두
엔진이고 캐리는 운용하지 않는다.** 이 문서의 캐리 판은 그때의 근거로 남긴다. 다시 볼 조건(예: 최근
12개월 펀딩이 연 X% 이상)은 정하지 않았다 — 필요하면 결과를 보기 전에 별도 이슈로 못 박는다.

## §10 후속 확인(2026-10-14 · 탐색 · 캐리 0% 기준)

사용자 질문 「실제로 자본이 모자라 진입 못 하는 경우가 있나」에 대한 탐색 측정이다(스크래치 · 판정 아님).

  사유가 전부 `cell_busy`(같은 칸에 이미 포지션 · 현물 6건 + 선물 18건)이고 `notional`(명목 상한 소진)

  2.29배(2024-08-05). 한 거래 명목은 중앙 0.08배 · 최대 0.32배.
* **계좌 레버리지별 필요 증거금 최대**: 2배 → 115%(넘는 날 2일 — 진입이 막히거나 줄어든다) · **3배 →
