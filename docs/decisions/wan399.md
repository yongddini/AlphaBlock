# WAN-399 — 페이퍼 리셋은 「장부 CSV 내보내기 → DELETE」까지만 한다

- 날짜: 2026-09-18
- 결정: 사용자 (2026-09-07 「그냥 DELETE로 해」 · 「기존 백업을 받지말고 그냥 거래내역을 삭제」 ·
  2026-09-18 완료기준 7 = 「지우기 전에 CSV로 자동 내보내기」)
- 범위: `scripts/paper-reset.sh` 한 파일 + 회귀 테스트 · 전략·엔진·DB 스키마·기본값·토대 불변 ·
  실거래 보류 유지(`ALPHABLOCK_LIVE_TRADING=false`)

## 1. 바뀐 것

| | WAN-399 이전 | **이후** |
| -- | -- | -- |
| 기본 실행 | 백업 ＋ DELETE ＋ VACUUM | **CSV 내보내기 ＋ DELETE** |
| DB 전체 백업 | 기본 켬(`--no-backup`으로 끔) | 기본 끔 · `--backup` 옵트인(여전히 `db-backup.sh` 경로) |
| VACUUM | 무조건 | 기본 끔 · `--vacuum` 옵트인 |
| 장부 기록 | 백업 파일 속(수 GB 통째) | `<DB 디렉터리>/paper-reset-exports/YYYYmmdd-HHMMSS/*.csv` |
| `--no-backup` | 백업 끔 | 무동작 ＋ 「이제 기본입니다」 안내 |
| `--help` | `sed -n '2,40p'` — 코드 10줄이 샜다 | 머리말 끝(첫 비-주석 줄)에서 멈춘다 |

## 2. 왜

- **백업·VACUUM은 헛수고였다.** 지우는 것은 장부 4개 테이블의 수백 행인데 둘 다 DB 파일(로컬
  사본 실측 7.9GB)을 통째로 다시 쓴다. 시세(`ohlcv`·`funding_rate`)가 같은 파일에 있고 그게 용량의
  거의 전부라 VACUUM이 회수할 공간도 사실상 없다. doctor 전수가 18분 걸리는 디스크라(WAN-318 §1)
  그동안 수집기·러너와 디스크를 다툰다.
- **재-베이스라인 리셋은 장부를 일부러 버리는 일이다** — 옛 규칙 기록은 새 규칙 성과와 섞이면
  못 쓴다. 백업이 지키려는 「잘못 지운 것 되돌리기」가 이 경우엔 없다.
- **그런데 기록 자체는 남아야 한다(완료기준 7).** WAN-409 §3이 2026-09-01 리셋에
  `live_limit_orders`를 잃어 「판정 불가」로 닫혔다 — `alphablock cascade` 도구는 있는데 표본이
  없었다. 그래서 장부는 **DB에서는 비우되 파일로는 남긴다.** WAN-392 §5가 손으로 한
  `paper_trades_pre_wan392.csv`(지금 WAN-398의 입력)의 자동화다.

## 3. 내보내기 계약

1. **순서**: 러너 정지 확인 → CSV 내보내기 → (옵트인 백업) → DELETE → (옵트인 VACUUM) → 재시작.
2. **대상**: `PAPER_TABLES` 4개 전부(`paper_trades`·`open_positions`·`live_limit_orders`·
   `live_runner_sessions` — 전부 작다). 개발자 판단: `live_limit_orders`만이 아니라 4개 전부 —
   세션·포지션 기록이 체결 기록을 해석하는 맥락이고 크기가 무시할 만하다.
   - ❌ `PROTECTED_TABLES`(시세)는 **절대** 안 내보낸다 — 애초에 안 지우고 수 GB다.
   - ❌ `--include-backtest`의 `backtest_*` 5개도 안 내보낸다 — `backtest.run --persist`로
     코드에서 다시 적재할 수 있고 클 수 있다(개발자 판단).
3. **검증**: 헤더는 `pragma_table_info`에서 항상 쓰고(0행 테이블도 열 이름이 남는다) CSV를 메모리
   DB로 **다시 읽어** 레코드 수가 원본 `COUNT(*)`와 같은지 본다 — 줄 수가 아니라 레코드 수라
   따옴표 안 줄바꿈이 있어도 정확하다. 명령은 stdin으로 넘긴다(옛 sqlite3 호환).
4. 🚨 **실패하면 삭제하지 않는다**(종료 코드 1) — 디렉터리를 못 만들거나 · 한 테이블이라도 못
   내보내거나 · 행 수가 어긋나면. 기록 없이 장부만 사라지는 것이 이 결정이 막으려는 결과다.
5. **덮어쓰지 않는다** — 실행 시각 디렉터리를 `mkdir`(‑p 없이)로 새로 만들고, 이미 있으면 멈춘다.
6. ⚠️ **한계**: CSV는 NULL과 빈 문자열을 가르지 못한다. 측정 원자료로는 충분하지만 DB로 비트
   복원하는 수단은 아니다(그게 필요하면 `--backup`).

## 4. 안 바뀐 것

- **러너 정지 확인**(서비스가 하나라도 active면 삭제 중단) — 이 스크립트의 진짜 안전장치.
- 지우는 테이블 목록(`PAPER_TABLES`·`BACKTEST_TABLES`·`PROTECTED_TABLES`).
- 백업 위임(`db-backup.sh` — WAN-318이 잘린 백업 사고 뒤 만든 검증 경로).
- 마지막 `if` 블록 — 단축평가(`[[ … ]] && log`)로 되돌리면 백업이 꺼진 **기본 실행이 매번**
  `set -e` 아래 종료 코드 1이 된다. 회귀 테스트가 기본 실행 종료 코드 0을 고정한다.
- `deploy.sh`와 묶지 않는다(배포 → 리셋 순서는 사람이 밟는다).
