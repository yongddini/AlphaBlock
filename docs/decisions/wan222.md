# WAN-222: 지정가 유효기간(`limit_valid_bars`) 스윕 — 유효기간이 체결률·수익에 미치는 영향

- **일자**: 2026-08-01
- **상태**: 측정 완료 — **기본값·토대 불변**(`limit_valid_bars=24` 유지, 변경은 재-베이스라인 = 사용자 결정)
- **도구**: 범용 CLI에 `--limit-valid-bars` 축 추가(WAN-101 방침 — 전용 리포트 스크립트 대신 CLI 축)
- **재현**: `uv run python -m backtest.run --limit-valid-bars 6,12,24,48,none --oos-warm --jobs auto --format csv --out backtest/reports/wan222_limit_valid_bars_sweep.csv`
- **산출물**: `backtest/reports/wan222_limit_valid_bars_sweep.csv`(540행 = 9종목 × 3TF × 5값 × 4구간)

## 0. 질문 — 사용자 원문 (2026-07-31)

> "유효기간이 얼마나 되고, 이게 체결률에 영향 주지 않느냐"

지정가 주문은 `limit_valid_bars`(기본 **24봉**) 동안만 살아 있고 그 안에 가격이 안 닿으면
취소된다(`no_fill`). 단위가 **그 칸의 TF 봉 수**라 실제 대기 시간이 주기마다 다르다(24봉 =
15m **6시간** · 1h **24시간** · 4h **나흘**). 이 값을 다른 값과 비교해 측정한 적이 없어 24는
**검증되지 않은 기본값**이었다. 페이퍼 러너의 1순위 목적이 「닿으면 체결」(baseline) 가정의
체결률 실측인데, 그 체결률을 **직접 좌우하는 손잡이가 바로 이 유효기간**이다.

## 1. 도구 — `--limit-valid-bars` 축

`--tp-r`·`--offset-bps`와 같은 전략 축으로 열었다(콤마 복수 = 격자). `none` = 무기한(존
무효화까지 대기). **존폭 필터(`--max-zone-width-atr`)와 같은 `UNSET` 센티넬 규약** — `none`
(무기한)은 **유의미한 값**이라 「인자 미지정(= 채택 기본값 24 물려받음)」과 갈라야 한다.
안 가르면 「유효기간 24」 실행에 「무기한」 라벨이 붙는 조용한 실패가 된다(WAN-91/95/112/123
부류). 회귀 테스트가 **라벨이 아니라 동작**으로 고정한다: 미지정 == 명시적 24 비트 동일 ·
`1` != `none` · `none`이 유한 유효기간보다 셋업을 더(≥) 살려 둠(만료는 취소만 하지 더하지
않으므로 eligible은 유효기간에 단조 증가). 북 모드는 이 축을 거부(per-cell 단일로 접힘) —
체결률은 칸 단위 성질이라 북 집계가 아니라 per-cell 단일에서 읽는 게 맞다.

## 2. 측정 — 판정 (c) TF에 갈리되 **방향은 하나**

좌표는 채택 기본값 그대로(9종목 × 15m·1h·4h × 못 박은 6년 창 2020-09-15~2026-07-22 ·
`baseline` 단독 · 필터 1.28 · `intrabar_live` · `unconditional` · 오프셋 2bp). 정본 OOS는
`--oos-warm`(WAN-166). 심볼평균 `oos_warm`(주 수치):

| TF | 지표 | 6봉 | 12봉 | 24봉(현행) | 48봉 | none(무기한) |
| -- | ---- | --: | --: | --: | --: | --: |
| **15m** | 체결률% | 68.81 | 69.81 | 73.29 | 75.88 | **80.24** |
|      | 수익% | 37.99 | 37.48 | 37.06 | 36.05 | 39.11 |
|      | 승률% | 54.42 | 54.29 | 54.03 | 53.86 | 54.23 |
|      | MDD% | 6.15 | 6.18 | 6.00 | 6.04 | 6.26 |
| **1h** | 체결률% | 62.43 | 63.59 | 67.53 | 69.93 | **75.03** |
|      | 수익% | 17.65 | 17.71 | 18.39 | 19.15 | **21.84** |
|      | 승률% | 54.79 | 54.75 | 54.66 | 54.96 | 55.61 |
|      | MDD% | 5.52 | 5.57 | 5.85 | 5.86 | 5.65 |
| **4h** | 체결률% | 67.86 | 69.06 | 72.18 | 74.14 | **75.92** |
|      | 수익% | 8.09 | 8.18 | 8.59 | 8.94 | 8.86 |
|      | 승률% | 57.23 | 57.49 | 57.70 | 58.00 | 57.79 |
|      | MDD% | 3.13 | 3.13 | 3.21 | 3.21 | 3.32 |

- 📌 **체결률은 유효기간에 확실히 오른다** — 6봉→none 심볼평균 **15m +11.4%p · 1h +12.6%p ·
  4h +8.1%p**(oos_warm). 종목별로도 거의 예외 없이 증가한다(9종목 × 3TF 중 미세한 비단조는
  꼬리 몇 셀뿐, 방향은 전부 +). full/is/oos 네 구간 모두 같은 모양이다. **사용자 질문의
  직접 답: 예, 유효기간이 체결률에 크게 영향을 준다(길수록 더 채워진다).**
- 📌 **그런데 그 늘어난 체결의 손익 기여는 작고 종목에 갈린다** — 승률·MDD가 거의 안 움직인다
  (15m 승률 54.0~54.4% 사이). 늦게 채워진 거래가 **평균만큼은 괜찮아서**(승률 희석 없음)
  수익을 크게 더하지도 깎지도 않는다. 「체결률이 높다 = 좋다」가 **아니다** — 완료기준의 경고
  그대로다.
- 📌 **1h만 근소하게 이득** — none이 24 대비 oos_warm **+3.45%p**(leave-one-out +2.4~+3.9%p로
  한 종목 산물이 아니다). **4h는 평평**(none이 48보다 오히려 살짝 낮다). **15m은 노이즈**
  (24→none이 −0.4~+2.1%p로 갈지자, SOL 한 종목이 **−10%p**로 끌어내린다).
- 📌 **24는 특별한 값이 아니다** — 체결률·수익 곡선이 매끈해 24에 꺾임이 없다. none이 더
  채우고 손익은 중립~근소 우위다. 하지만 **곡선이 매끈하다는 것 자체가 「24가 나쁘다」도
  아니다** — 어느 값이든 손익은 거기서 거기다.

## 3. 경고 · 범위 밖

- 🚨 **「none로 바꿔라」·「유효기간이 알파다」로 인용 금지** — 전부 `baseline`(닿으면 체결)
  낙관 렌즈 위의 값이다. 체결률 자체가 낙관적이라(큐 우선순위 미모델링) 실제 해소는 틱·호가
  (WAN-98) 소관이다. 유효기간을 늘리면 **더 늦게·더 불리한 타이밍에** 채워질 수 있는데
  baseline은 그 질을 구분하지 못한다 — 승률이 안 떨어지는 것도 이 낙관 가정 아래의 값이다.
- ⚠️ **「엣지 없음」(WAN-84/88/111/114/124/151/201) 불변** — 유효기간은 진입 규칙이 아니라
  **체결/기회의 모양**만 바꾼다(익절 R·레버리지가 위험의 모양만 바꾸는 것과 같은 부류, WAN-90).
- ⚠️ **신규 3종목(DOGE·LINK·LTC)은 펀딩 0행**(범용 CLI는 대리를 안 얹는다 — `funding_coverage`
  0%) — 그 3종목 수익은 소폭 부풀려져 있다. 체결률 질문에는 무관하다(펀딩은 체결률을 안 바꾼다).
- ❌ **기본값 변경 없음** — `limit_valid_bars=24` 유지. 24에서 바꾸는 것은 진입 규칙을 건드리는
  **재-베이스라인 = 사용자 결정**이다(개발자 임의 착수 금지). 토대·다른 기본값 불변 ·
  `ALPHABLOCK_LIVE_TRADING=false` 유지 · 실주문 무관.
