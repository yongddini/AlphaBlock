# WAN-236: 2h 타임프레임 성능 — 9종목 6년 따뜻한 OOS, 15m·1h·4h와 나란히

**성격** 측정 전용(채택 아님) · **새 코드 없음**(범용 CLI 한 줄, WAN-101 원칙) · 2h는
파생 TF(`data/storage.py`의 `_DERIVED_TIMEFRAMES = {"2h": "1h"}`, 저장된 1h봉 집계)라
엔진·전략·기본값·토대 불변(`ALPHABLOCK_LIVE_TRADING=false` 유지).

**재현**

```bash
# per-cell 단일 = TF 비교 표준 (WAN-130/206 방식)
uv run python -m backtest.run --tf 1h,2h,4h --oos-warm --positions single \
  --format csv --out backtest/reports/wan236_2h_compare.csv
# 체결 보수화 렌즈 병기
uv run python -m backtest.run --tf 2h --oos-warm --positions single --fill baseline,pen_5bp \
  --format csv --out backtest/reports/wan236_2h_fill.csv
# 채택 회계 = 레버리지 북(cap_only 5배, WAN-213) — 2h만
uv run python -m backtest.run --tf 2h --oos-warm \
  --format csv --out backtest/reports/wan236_2h_book.csv
```

원본:
`backtest/reports/wan236_2h_compare.csv`(1h·2h·4h × 9종목 × full/is/oos_warm/oos) ·
`backtest/reports/wan236_2h_fill.csv`(2h × baseline/pen_5bp) ·
`backtest/reports/wan236_2h_book.csv`(2h 채택 북, 구간당 집계).

좌표: 9종목 × 못 박은 6년 창(2020-09-15~2026-07-22, WAN-182) · 채택 기본값(오프셋 2bp ×
`intrabar_live` × `unconditional` × 필터 1.28 × 고정 1.5R × 롱 온리 × 분리 존) · 정본 OOS =
따뜻한 연속 `oos_warm`(주 수치) + 차가운 `oos`(과최적화 스트레스) 병기(WAN-166).

## 1. 판정 한 줄

📌 **2h는 이웃 TF 사이에 얌전히 자리잡는 「중간 TF」다** — 봉이 굵어질수록(1h→2h→4h)
수익·거래수·체결 취약성이 **단조로** 줄고 승률·MDD 방어는 **단조로** 좋아진다. 2h는
그 사슬의 정직한 보간점이고, **1h를 이기지 못한다**(수익 기준). 다만 2h는 **1h보다 편중이
덜하고**(ETH/SOL 쏠림 약함) **체결 보수화(`pen_5bp`)에 더 강하며**(86% 잔존, 0/9 음전환)
**표본 게이트를 여유롭게 통과**한다 — 짧은 TF들의 약점이 2h에선 완화된다. **채택 권고는
없다**(2h를 작업 TF로 올리는 것은 재-베이스라인 = 사용자 결정).

## 3. 함정 점검 (표 아래 명시 — 이 저장소 단골)

### 📌 표본 게이트 — 통과 (2h가 4h의 표본 문제를 물려받지 않는다)
2h OOS 거래수는 심볼당 **37~52건**으로 9종목 전부 WAN-84 기준(20건)을 여유롭게 넘는다
(최소 XRP 37 · 최대 ETH 52). 4h가 옛 3년창에서 미달이던 문제가 2h에는 아예 없다 — 2h는
4h보다 봉이 2배 많다.

### ⚠️ 편중(leave-one-out, oos_warm) — 2h는 1h보다 덜 쏠린다
종목을 하나씩 빼도 세 TF 모두 심볼평균이 견고하게 플러스이나, **집중도는 TF마다 다르다**:

| 빼는 종목 | 1h | 2h | 4h |
|-----------|---:|---:|---:|
| (전체) | +18.39 | +10.74 | +8.59 |
| ex-ETH | **+13.11** | +9.86 | +7.90 |
| ex-SOL | +16.31 | +9.56 | +8.06 |
| 최소~최대 | 13.11~19.97 | **9.56~11.80** | 7.70~9.66 |

📌 **1h는 ETH 하나가 −5.28%p를 만드는데(18.39→13.11), 2h는 어느 종목을 빼도 9.56~11.80%
범위**다 — 2h는 이 저장소에서 드물게 ETH/SOL 편중이 약하다(봉이 굵어 소수 종목의 대박이
평균을 덜 지배). 「플러스는 전부 ETH가 만든다」(WAN-84/88/111 계열)가 2h에선 약하게만
성립한다.

### ⚠️ IS→OOS 뒤집힘 — 없음
세 TF 모두 종목 부호 뒤집힘 0건(9종목 전부 IS·OOS 동부호). 수익 **크기**는 IS→OOS로
크게 준다(2h 34.4→10.7%, 정상적 과최적화 감쇠)지만 **부호는 안정**이다.

### ⚠️ 신규 3종목 펀딩 대리 — per-cell 경로는 미적용(부풀림), 북 경로는 적용
🚨 **회계마다 다르다**: per-cell 단일 경로(`backtest.run --positions single`)는 **펀딩 대리를
얹지 않으므로** DOGE·LINK·LTC의 `funding_coverage`가 **0%**다(§2 상세 표) — 이 3종목의
2h 수익(DOGE +7.73 · LINK +2.25 · LTC +10.03%)은 펀딩비 미계상으로 **소폭 부풀려져 있다**.
반면 **채택 북 경로**(`book_cli`, §5)는 `apply_funding_proxy`로 **BTC 도너 대리**(기존 확정
펀딩 평균 최고 = 롱에게 가장 비싼 종목의 시계열)를 얹는다(WAN-180 관행). ⚠️ 다만 이 3종목을
leave-one-out으로 빼도 2h 심볼평균이 거의 안 움직이므로(ex-DOGE 11.12 · ex-LINK 11.80 ·
ex-LTC 10.83), **부풀림이 판정을 바꾸지 않는다**.

### 📌 체결 보수화(`pen_5bp`) — 2h는 관통 요구에 강하다 (15m과 대조)
2h는 봉이 굵어 "스치듯 닿은 체결"에 덜 기댄다 — oos_warm 심볼평균이 baseline +10.74% →
`pen_5bp` +9.24%(**−1.50%p, 86% 잔존**)이고 **음전환 종목 0/9**(SOL·LINK는 오히려 상승).
15m이 관통 요구에 무너지던 것(WAN-96/124: 15m OOS 수익의 대부분이 마진 체결에 실림)과
**대조적**이다. 봉이 굵을수록 이 성질이 좋아진다는 사슬의 2h 지점이다.

| 종목(2h oos_warm) | baseline | pen_5bp | Δ |
|-------------------|---------:|--------:|---:|
| SOL | 20.18 | 22.65 | **+2.48** |
| LINK | 2.25 | 2.37 | +0.12 |
| BTC | 9.12 | 8.40 | −0.73 |
| LTC | 10.03 | 9.23 | −0.80 |
| XRP | 6.21 | 4.92 | −1.29 |
| TRX | 9.46 | 8.07 | −1.39 |
| BNB | 13.87 | 12.04 | −1.84 |
| ETH | 17.82 | 13.38 | −4.44 |
| DOGE | 7.73 | 2.13 | −5.61 |
| **심볼평균** | **10.74** | **9.24** | **−1.50** |

⚠️ DOGE의 큰 하락(−5.61%p)은 펀딩 대리 미적용(0% 커버리지)과 겹쳐 읽을 것 — 순수 체결
민감성만의 값이 아니다.

## 4. 채택 회계(레버리지 북 cap_only 5배)로 본 2h — 사용자 요청 「cap only + 일반 둘 다」

per-cell 단일(§2, 측정·비교 표준)에 더해, **채택 회계**인 레버리지 북(WAN-213, cap_only
5배 · 칸=(종목,TF)마다 1포지션 · 한 지갑 공유)으로 2h만 병기한다. ⚠️ 북은 **칸을 가로질러
공유 자본**이라 구간당 집계 1행이지 심볼별 분해가 아니다(형태가 per-cell과 다르다). 이 북은
9칸(9종목 × 2h)만 공유하므로 다중 TF 북(wan180 both)보다 겹침이 적다.

| 구간 | 거래수 | 승률 | 총수익%† | MDD% | 수익/MDD | 최대동시 | 최대동시리스크% | 청산 |
|------|------:|-----:|--------:|-----:|--------:|--------:|--------------:|----:|
| full | 1075 | 0.588 | +32.80 | 11.02 | 29.7 | 5 | 5.00 | 0 |
| is | 680 | 0.604 | +12.78 | 11.02 | 11.6 | 5 | 5.00 | 0 |
| **oos_warm** | 395 | 0.559 | **+1.45** | **9.35** | 15.5 | 4 | 4.01 | 0 |
| oos | 378 | 0.556 | +1.26 | 10.34 | 12.2 | 4 | 4.01 | 0 |

📌 **판단 근거는 총수익%가 아니라 위험 축이다**(WAN-169/180/213): 총수익%는 복리 착시라
실현 수익이 아니다 — 2h oos_warm의 **MDD 9.35% · 최대 동시 리스크 4.01% · 청산 0건 · 최대
동시 4칸**이 읽을 값이다. 신규 3종목 펀딩은 이 북에서 **BTC 도너 대리 적용됨**(per-cell
경로와 달리). 2h 단독 북은 겹침이 낮아(피크 4~5칸) 총수익 성장이 다중 TF 북보다 작다.

## 5. 「엣지」에 대하여 — 이 표는 엣지를 재지 않는다

🚨 **「2h에서 엣지 찾았다」로 인용 금지** — 여기 수치는 전부 `baseline`(닿으면 체결) 렌즈
위의 성능 측정이고, **「진입 규칙이 무작위와 구분되는가」는 다른 질문**이다. 그 매칭 널
(WAN-242식, 볼린저 무력화 축 × 20시드)은 봉내 라이브 밴드 고유 비용으로 무거워 **후속
WAN-243**으로 분리됐다. 「엣지 없음」(WAN-84/88/111/114/124/151/201)은 이 측정이 뒤집는
대상이 아니다.

## 6. 결론 · 범위

- **2h는 1h와 4h 사이의 정직한 중간 TF**다 — 수익은 1h에 못 미치지만, 편중·체결 취약성·
  표본 문제가 짧은 TF보다 완화된다. warm/cold gap 최소·부호 뒤집힘 0으로 강건성 지표도 좋다.
- **채택 권고 없음** — 2h를 작업 TF·수집 대상으로 올리는 것은 **재-베이스라인 = 사용자
  결정**이다. `DEFAULT_TIMEFRAMES`(15m·1h·4h)·수집기·기본값·토대 전부 불변.
- 📌 **2h는 파생(1h 집계)이라 1h 데이터 품질에 종속** — 1h 커버리지가 완전해(9종목 전부
  2020-09~2026-07 연속) 2h도 공백 없이 돌았다.
- 재진입 엣지 판정(2h 축)은 **WAN-243** 소관.
