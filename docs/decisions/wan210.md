## 1. 왜 재는가 — WAN-150이 부호로 반증했고, 사용자가 뒤집어 물었다

[WAN-150](wan150.md) §3이 사용자의 RSI-EMA 곡률 가설(∩+하락=롤오버=즉사)을 **부호로
반증**했다: 즉사를 부르는 건 롤오버가 아니라 **과열된 반등(높은 RSI)에 올라타는 것**이었다
(`tap_rsi`가 즉사 대 승자에서 +0.137(15m)·+0.115(1h) OOS 상관, 방향 OOS도 무작위 초과).
사용자가 *"반대로 하면?"* 이라 물었다 — 부호를 뒤집어 **RSI가 높은 상태의 진입을 거르는
상한 게이트**가 실제로 즉사를 줄이고 수익을 올리는지 손익으로 본다. 🚨 이건 사실상 **「RSI
상한 게이트」** 이고, [WAN-123](wan123.md)이 RSI 재탭 게이트를 **순손해라서 제거**한 전례가
있다(성격은 다르나 RSI로 진입을 거르는 시도).

## 2. 무엇을 어떻게 쟀나 — 두 갈래(싼 길/비싼 길)

* **좌표**: 9종목 × 못 박은 6년(2020-09-15~2026-07-22) × 15m·1h·4h · 채택 기본값(필터 1.28 ·
  `intrabar_live` · `unconditional` · 오프셋 2bp · 고정 1.5R · 롱 온리 · 분리 존) · 공식 렌즈
  `baseline`(+ Part B `pen_5bp` 재검). **핀 없음**.
* **라벨 재사용**: `wan150_labeled.csv`(핀 없는 오늘 엔진 · 필터 1.28 켜짐)의 즉사/승자
  라벨과 `tap_rsi`·`rsi_ema_slope`·`zone_width_atr`를 그대로 쓴다(새 라벨 안 만듦).
  funding=False도 WAN-150과 같다(즉사 분류에 펀딩 무관 · 매칭 널은 같은 풀 안 상대 대조).
* **게이트**: `값 ≥ IS 분위 문턱이면 진입 스킵`(상한 게이트). 문턱은 **IS에서 고르고 OOS
  검증**, 제거 비율 상위 1/4·1/3·1/2 **전수 병기**(IS 1등 뽑기 금지, WAN-90/161).
* **Part A(싼 길 · 3 TF · 서브스텝 없음)**: §1 즉사 매칭 널 · §2 존폭 통제 편상관 ·
  §3-bis 지속-심화 추세 · leave-one-out. `wan150_labeled.csv` + HTF 프레임만.
* **Part B(비싼 길 · 후보 재빌드)**: 게이트를 후보 단계에 걸고 **재시퀀싱**한 `total_return`·
  승률·MDD·즉사율(default/filter/matched) + `pen_5bp` 재검. 후보 재빌드가 무거워
  `--timeframes`/`--append`로 나눠 돈다.
* **검산**: 게이트 off(전 후보) 시퀀싱 num_trades ≡ 생산 `run_once` num_trades ≡
  `wan150_labeled.csv` 셀 카운트(BTC 1h: 254 = 254 = 254, `--checksum`).

## 3. §1 — 게이트가 무작위 제거보다 즉사를 더 잘 줄이는가 (즉사 대 승자 매칭 널)

공식 렌즈 즉사 대 승자, `p_death` = 무작위 제거(20시드)의 즉사율이 게이트 이하일 확률(단측,
낮을수록 게이트 우위). 요지:

* **`tap_rsi` 상한 게이트는 15m·1h OOS에서 무작위를 넘는다** — 15m OOS는 제거 1/4·1/3·1/2
  세 문턱 전부 `p_death=0.048`(즉사율 20.35% → 18.9/17.8/16.4%), 1h OOS는 1/3·1/2에서
  `p_death=0.048`(20.38% → 18.1/15.3%). 4h는 무작위를 못 넘는다(표본 148).
* **`rsi_ema_slope` 상한 게이트는 15m·1h에서 대체로 무작위 수준**(15m OOS 제거 1/4·1/3
  p=0.38·0.14) — 단 **4h에서만** 무작위를 넘는다(OOS p=0.048).
* 🚨 **그러나 오폭(승자 제거율)이 73~83%다** — 게이트가 잘라내는 것의 3/4가 승자다.
  즉사를 조금 더 잘 걸러도 승자를 훨씬 더 많이 버린다 → **손익분기 관점에서 P&L이 오를지는
  §5(Part B)가 정한다**(즉사율 감소만으로는 근거가 아니다 — 되짚으면 항상 참).

## 4. §2 — 존폭과 독립인가 (채택 판단의 관문)

`tap_rsi`↔즉사(즉사 대 승자) 상관을 `zone_width_atr`로 통제한 **편상관** + 심볼 층화 순열:

* **15m: (a) 독립** — raw +0.137 → **partial +0.095, p=0.0000**. 존폭을 걷어내도 절반 이상
  남고 유의. 15m에서 과열-RSI 축은 존폭 필터가 잡는 것과 **부분 독립**이다.
* **1h: (b) 공선** — raw +0.115(p=0.006) → **partial +0.057, p=0.19**. 존폭을 통제하면
  붕괴 = 게이트가 존폭 필터 1.28이 이미 고르는 것을 재선별하는 것에 가깝다.
* **4h: (b)** — `tap_rsi` raw가 OOS 무작위를 못 넘는다(+0.016, p=0.87).
* 📌 `rsi_ema_slope`는 다르게 갈린다 — 15m/1h OOS는 무유의, **4h OOS만** raw +0.205(p=0.013)·
  partial +0.185(p=0.033)로 존폭 독립처럼 보이나 **표본 148**이라 무게가 약하다.

즉 **독립성은 TF·특징에 갈린다** — 15m `tap_rsi`만 존폭과 부분 독립이고, 1h는 공선, 4h는
`rsi_ema_slope` 쪽만 (표본 적게) 독립이다.

## 5. §3-bis — 지속-심화 추세(사용자 정정): 원래 방향(롤오버→즉사)도 성립하지 않는다

사용자 정정(2026-07-29): WAN-150이 잰 RSI-EMA 곡률은 **한 봉 스냅샷**이라 원래 롤오버 그림
(여러 봉에 걸친 지속 심화)이 아니다. RSI-EMA 기울기가 "0에서 계속 음수로 벌어지는지"를 세
조작화(연속 심화 `deepen_run`·N봉 단조 하락 `monotone_fall`·N봉 기울기 추세 `slope_trend`)
× **N∈{4,5,6}**(착수 전 못박음)로 만들어 같은 자(즉사 대 승자 상관)로 검정했다(닫힌 봉만 ·
룩어헤드 없음, 회귀 테스트가 동작으로 고정).

📌 **어느 TF·N에서도 지속-심화는 즉사를 예측하지 못한다** — OOS 상관이 전부 |corr|<0.13이고
유의(p<0.05)한 셀이 **하나도 없다**(15m: −0.02~+0.01 · 1h: −0.04~+0.01 · 4h: −0.13~+0.03).
방향조차 가설(심화→즉사, corr>0)과 자주 어긋난다. **WAN-150의 스냅샷 반증에 이어, 롤오버
가설을 "제대로(지속-심화)" 조작화해도 살아나지 않는다** — 사용자의 원래 롤오버 그림은
스냅샷·지속 어느 쪽으로도 즉사를 예측하지 못한다.

## 6. leave-one-out — `tap_rsi` 게이트는 ETH 편중이 아니다

`tap_rsi` 게이트의 OOS 즉사율(제거 1/3)은 어느 종목을 빼도 기본(20.35%/20.38%)보다 낮게
유지된다(15m 16.7~18.8% · 1h 16.9~20.4%). 15m/1h의 즉사 감소는 **한 종목이 만드는 것이
아니다**(이 저장소의 반복된 ETH 편중과 대조).

## 7. Part B — 실제 시퀀싱 손익 (게이트 off vs on vs 무작위 제거) · 결정적 leg

1h·4h(9종목 · baseline + pen_5bp)를 냈다(15m은 후보 재빌드가 6년 1분봉에서 무거워 후속
`--timeframes 15m --append`로 낸다 — Part A는 15m을 이미 완비했고, 아래 결론은 그것과
1h/4h 손익으로 이미 결정된다). 심볼평균 `total_return`, `p_return` = 무작위 제거가 필터
이상으로 벌 확률(단측).

📌 **두 대조를 갈라 읽어야 한다** — 판정이 여기서 갈린다:

* **필터 대 무작위 제거**: `tap_rsi` 게이트가 **무작위를 이긴다** — 1h는 제거 1/4·1/3·1/2
  세 문턱 전부 `p_return=0.048`(baseline · **pen_5bp에서도 0.048**). 즉 "높은 RSI를 버리는
  것"은 "무작위로 버리는 것"보다 낫다 = **뒤집은 가설의 방향이 맞고, 체결 보수화(pen_5bp)를
  견딘다**(마진 체결의 산물이 아니다). §3 즉사 매칭 널과 정합.
* 🚨 **필터 대 default(게이트 off)**: 게이트가 **진다** — 1h `tap_rsi` IS default **+77.68%**
  vs filter +53~64%, OOS default **+18.39%** vs filter +15.07~18.74%(대부분 default 이하,
  0.33만 +0.35%p로 노이즈 수준). 즉사율은 실제로 준다(1h OOS 14.41% → 12.27%@0.5)**는데
  수익도 같이 준다** — §3의 오폭 73~83%가 손익으로 확인된다: **즉사를 조금 덜 맞는 대가로
  승자를 훨씬 더 많이 버려서, 게이트를 켜면 그냥 안 켠 것보다 못하다.**
* `rsi_ema_slope` 게이트는 더 약하다 — 무작위조차 OOS에서 자주 못 넘는다(1h OOS p=0.19~0.48).
* **4h는 필터가 default·무작위 양쪽에 진다**(OOS p=0.19~1.0 · 유효 심볼 1~4로 표본 붕괴).
* **pen_5bp에서도 그림이 같다** — `tap_rsi`는 무작위를 계속 이기되(p=0.048) default엔 계속
  진다(OOS default +15.42% vs filter +13.04~16.11%).

📌 **핵심**: 신호는 진짜다(무작위 초과 · pen_5bp 생존 · 15m 존폭 독립). **그러나 그 신호로
진입을 거르면 켜기 전보다 총수익이 낮다** — WAN-90/137이 반복한 "위험의 모양만 바꾼다"의
사촌으로, 여기서는 **모양도 안 좋아진다**(수익↓ · 즉사만 소폭↓).

## 8. 판정 · 인용 경고

📌 **판정: (b) 닫는다 — 채택 권고 없음.** 뒤집은 가설의 방향은 맞다(과열 RSI 회피가 무작위
제거를 이기고 pen_5bp를 견디며 15m에선 존폭과 부분 독립). **그러나 그 신호로 진입을 거르면
켜기 전(default)보다 총수익이 낮다** — 즉사를 소폭 줄이는 대가로 승자를 3배 더 버린다(오폭
73~83%). §2에서 유일하게 존폭과 독립이던 15m조차 P&L 관문은 별개이고, 1h/4h·pen_5bp가 모두
default 우위다. **이는 [WAN-123](wan123.md)이 RSI 재탭 게이트를 순손해라서 제거한 결론의
재확인**이다(RSI로 진입을 거르는 시도가 다시 net loss). 롤오버 가설을 지속-심화로 제대로
조작화한 §3-bis마저 어느 TF·N에서도 살아나지 않는다.

* 🚨 **채택 권고 없음(사용자 결정 · 개발자 임의 착수 금지).** 근거는 §7(Part B): default ≥ filter.
* 📌 **15m Part B는 후속 append** — Part A(15m 신호 최강 · 존폭 독립)와 1h/4h 손익으로 판정은
  이미 정해졌다. 15m P&L이 default를 이길 개연성은 낮다(오폭 74~75%가 15m에서도 크다).
* 🚨 **이건 「RSI 상한 게이트」다** — [WAN-123](wan123.md)이 RSI 재탭 게이트를 순손해라서
  제거한 전례를 상기할 것.
* ⚠️ **「엣지 없음」(WAN-84/88/111/114/124/145/151) 뒤집기 인용 금지** — 다른 질문(*이미
  진입한 손절 중 즉사를 진입 시점에 거르는가*)이다.
* 전부 `baseline`(낙관) 렌즈 위 · Part B가 `pen_5bp` 재검을 낸다(게이트가 마진 체결에
  기대는지).
* **기본값·토대 불변** · `ALPHABLOCK_LIVE_TRADING=false` 유지(측정 전용).
