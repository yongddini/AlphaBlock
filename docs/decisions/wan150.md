# WAN-150 — 즉사 부검: 손절을 「즉사」와 「애매 실패」로 갈라 본다

**판정: (c) 즉사는 진입 시점에 「보이지만 기하로 판명」된다.** 게이트는 기계적으로 (a)를
찍지만, 세 TF·전 구간에서 강건한 지배 축은 `zone_width_atr`·`stop_width_atr`(ATR 단위
장벽 거리)뿐이고 이는 WAN-117 §1·WAN-133·WAN-152가 거듭 「선별이 아니라 기하」로 지목한
그 축이다. **사용자가 못박은 RSI-EMA 곡률(∩+하락) 가설은 부호로 반증됐다.** 새 필터
채택은 권고하지 않는다 — 기본값·토대 불변.

* 재현: `uv run python -m backtest.wan150_instant_death_autopsy`(검산만 `--checksum`)
* 표: `backtest/reports/wan150_summary.md` · `wan150_labeled.csv`(거래별 3분류·특징) ·
  `wan150_permutation.csv`(검정 통계량) · `wan150_quantile.csv` · `wan150_leave_one_out.csv`
* 창·유니버스: 못 박은 6년 창 **2020-09-15~2026-07-22** · **9종목** · 15m·1h·4h ·
  공식 렌즈 `baseline` 단독
* 엔진: **오늘의 채택 기본값**(오프셋 2bp × `intrabar_live` × `unconditional` × 존폭 필터
  1.28 × 고정 1.5R × 롱 온리 × `combine_obs=False`) — **핀 없음**(`ConfluenceParams()` ·
  `OrderBlockParams()`)
* **기본값·토대 불변**(측정 전용, `ALPHABLOCK_LIVE_TRADING=false` 유지)

## 1. 무엇을 물었나

WAN-117 존 실패 부검이 손절/익절 **2분류**로 11개 특징을 검정해 `zone_width_atr` 하나 빼고
전멸시켰다. 사용자 질문(2026-07-21): *"1.5배를 못 가고 손절한 경우가 많아서 … 즉사 거래를
좀 걸러낸다면 수익률이 많이 차이가 날까? 이런 거래를 잘 추려내기 위해서는 뭘 볼 거 같아?"*

물리적 그림이 다르면 2분류로 뭉치는 순간 신호가 희석된다:

* **즉사** = 존에 닿자마자 반대로 간다(MFE < 0.5R) → "파는 힘이 살아있는 채로 존에 들어왔다".
* **애매 실패** = 반등은 했으나 힘이 빠져 1.5R 전에 되돌아온다(0.5R ≤ MFE < 1.5R).
* **승자** = 1.5R 익절 도달.

이 이슈는 그 둘을 처음으로 가른 뒤, **진입 시점에 이미 아는 값**으로 즉사를 알아볼 수
있는지 묻는다. 새 신호를 찾는 게 아니라 **2분류로 놓쳤을 가능성 하나를 공정하게 닫는** 이슈다.

## 2. 무엇을 했나 — 오늘 엔진에서 라벨을 다시 뽑는다 (§0)

옛 `wan117_labeled.csv`는 **병합 존 · 옛 밴드 `tap` · 3종목 · 필터 없음**에서 만들어져 오늘
엔진의 분류가 아니다(사용자 결정 2026-07-29: "라벨을 다시 뽑는다"). 새 모듈
`backtest/wan150_instant_death_autopsy.py`는 WAN-117 골격을 **import로** 물려받고
(`_FeatureExtractor`·순열 자·Bonferroni — 새 파이프라인 금지, WAN-101), 두 곳만 바꾼다:

1. **오늘 기본값**을 쓴다 — `order_block_params=OrderBlockParams()`(`combine_obs=False`) ·
   `ConfluenceParams()`(밴드 `intrabar_live` · 필터 1.28). WAN-117은 `LEGACY_OB_PARAMS`·
   `pin_band_bar`로 옛 엔진에 고정돼 있었다.
2. **3분류 라벨**(MFE 기반) — `TAKE_PROFIT`→승자 · `STOP_LOSS`는 `cand.mfe_r`<0.5R→즉사,
   아니면 애매. `mfe_r`은 WAN-90이 넣은 시뮬레이터 필드를 그대로 읽는다(측정 전용).

**검산(§0)**: BTC 1h 셀의 시퀀서 거래 수 = **254 ≡ 채택 엔진 `run_once` num_trades 254**
(비트 일치, `--checksum`). 라벨링이 프로덕션 시퀀서(`sequence_with_candidates`)를 그대로
쓰므로 라벨 재생성이 인자 없는 `backtest.run`과 정합함의 독립 증거다. 전 격자에서
`sequenced == labeled`(END_OF_DATA 0 · MFE결측 0).

## 3. §1 게이트 — 즉사가 진입 시점에 보이는가

두 종속변수를 심볼 층화 라벨 순열(2,000회)로 검정했다: **즉사 대 나머지**(주 검정,
Bonferroni α/11) · **즉사 대 승자**(실무 문턱, {즉사,승자} 부분집합, α=0.05 무작위 초과).
게이트는 기계적으로 세 TF 모두 **(a)** 를 찍는다 — 무작위를 넘는 특징이 있다. 그러나
**무엇이** 넘는지가 판정을 (c)로 만든다.

### 넘는 것은 기하 하나다 — `zone_width_atr`

공식 렌즈 OOS 점이연 상관(즉사 대 나머지 · 즉사 대 승자):

| 특징 | 15m OOS 주/실무 | 1h OOS 주/실무 | 4h OOS 주/실무 | 가설방향 |
| -- | -- | -- | -- | -- |
| `zone_width_atr` | **+0.166 / +0.208** (p=0) | **+0.153\*/+0.211** (p=0) | +0.10~ / +0.14 | 중립(0) |
| `stop_width_atr` | +0.174 / +0.221 (p=0) | +0.164 / +0.228 (p=0) | +0.184 / +0.227 | ✗ |
| `tap_rsi` | +0.102 / +0.137 (p=0) | (IS만) | — | ✗ |
| `approach_mom` | +0.078 / +0.107 (p=0) | — | — | ✗ |
| `freshness_bars` | −0.053 / −0.071 | — | — | ✗ |
| `rsi_ema_*`(§3) | 유의하나 **전부 ✗** | — | 유의하나 ✗ | ✗ |

*(1h 주검정 `zone_width_atr`는 IS p=0 · OOS도 Bonferroni 통과.)*

* **`zone_width_atr`이 가장 크고 유일하게 강건하다** — 세 TF·양 구간 전부 corr
  +0.13~+0.17, p=0.0000. **leave-one-out에서 9종목 어느 하나를 빼도 부호·크기 불변**
  (15m OOS +0.161~+0.175) — 이 저장소의 상습 ETH 편중이 **아니다**.
* 그런데 이 축은 **WAN-117 §1·WAN-133·WAN-152가 세 번 「선별이 아니라 장벽 기하」로
  지목한** 바로 그것이다: 손절 −1R·익절 +1.5R이 고정인데 존폭/ATR은 그 ±장벽이 변동성
  대비 얼마나 멀리 서는지를 정한다. **넓은 존일수록 +1.5R이 ATR 단위로 더 멀어 닿기 전에
  손절된다** = 즉사. `stop_width_atr`(손절폭÷ATR)이 같은 부호·같은 크기로 살아나는 것이
  같은 채널임을 못박는다(둘 다 「존이 ATR 대비 넓다」의 두 얼굴이다).

### §2 — 손절폭: 척도가 갈린다 (기하 재확인)

`stop_width_atr`(ATR 정규화)은 강하게 유의하지만 **가설과 반대 방향**(넓은 손절일수록 즉사),
`stop_width_frac`(가격 대비 %)은 훨씬 약하고 들쭉날쭉하다. 가설("좁은 손절이 노이즈에
털려 즉사")은 **반증**됐다 — 즉사를 가르는 것은 손절폭의 절대 크기(%)가 아니라 **변동성
대비 장벽 거리**(÷ATR)다. ⚠️ 존폭 필터 1.28 + WAN-79 가드(0.3%)가 이미 좁은 셋업을 잘라
**관측 손절폭 하한이 정확히 0.300%**(가드 미만 0건)라, %척도는 하한에서 절단된 표본 위의
값임을 전제로 읽어야 한다.

### §3 — 사용자의 RSI-EMA 곡률 가설은 부호로 반증됐다

사용자 가설(2026-07-29): *"RSI의 지수이동평균이 위가 볼록(∩)한 채로 하락하면 존을 뚫고
내려가는(즉사) 경향"*(매도 힘이 살아있는 롤오버). 못박은 사양대로 RSI(14) 위 EMA(span14)의
기울기 `d1`·곡률 `d2`·불리언 `death_shape=(d1<0 & d2<0)`을 **탭 직전 확정봉**에서 계산했다
(룩어헤드 없음 — 회귀 테스트가 미래 봉 절단 불변으로 동작 고정).

결과는 유의성은 있으나 **방향이 가설과 정반대**다:

* `rsi_ema_death_shape`(∩+하락)의 15m OOS corr = **−0.053**(p=0.010) — death_shape=1이면
  즉사가 **더 적다**(가설은 +). 사용자의 물리적 직관이 부호로 반증됐다.
* `rsi_ema_slope`(d1)는 15m/4h OOS에서 유의하지만 **양의 상관**(RSI-EMA가 **오르며**
  탭할수록 즉사) — 이는 `tap_rsi`가 즉사와 **양**(높은 RSI에서 탭할수록 즉사)인 것과
  같은 그림이다: 하락 추세 롱에서 **과열된 반등(높은/오르는 RSI)에 올라타면** 되돌아
  즉사한다. 즉 즉사를 부르는 건 "롤오버"가 아니라 **"강세에 사는 것"**이다.
* 어느 셀도 가설방향(○)으로 유의하지 않다. RSI-EMA 곡률은 **즉사의 예측자가 아니다**(정확히는
  가설 반대 방향의 약한 상관이라 필터로 쓰면 즉사를 **키운다**).

## 4. 판정 — (c) 보이지만 기하

* **게이트 기계값은 (a)** — 즉사 축에서 무작위를 넘는 특징이 있다(11개 중 15m 6개·1h 3개·
  4h 1개가 실무 문턱 통과).
* **그러나 강건한 지배 축은 `zone_width_atr`/`stop_width_atr` 하나**이고, 이는 **선별이
  아니라 장벽 기하**다(WAN-117 §1과 같은 자리 · leave-one-out으로 기하임이 오히려 더
  분명해진다 — 종목을 안 가리는 것은 "좋은 존을 고른다"가 아니라 "고정 R ÷ ATR"이라는
  산수이기 때문이다). 나머지 생존자(`tap_rsi`·`approach_mom`·`freshness_bars`·`rsi_ema_*`)는
  **전부 가설과 반대 방향**이라 "가르는 값"이 아니라 "강세 진입이 되돌아온다"는 가격
  맥락의 재확인이고, 존폭/ATR과 공선일 공산이 크다.
* 따라서 **(c) 즉사는 진입 시점에 보이지만 「기하」로 판명** — WAN-133/152의 「존폭: 기하
  대 선별」 계열에 합류한다. **필터로 쓸 새 선별 축은 나오지 않았다.**

### 무엇을 하지 않는가

* **필터 채택을 권고하지 않는다.** `zone_width_atr` 축은 이미 존폭 필터 1.28(WAN-159)로
  채택돼 있고, 이 표는 그것을 **다른 통계량(즉사율)으로 재확인**했을 뿐 새 축을 열지 않는다.
  더 조이는 것은 WAN-203이 (평평/역전)으로 닫았다.
* **사용자 RSI-EMA 가설은 닫는다** — 부호가 반대라 필터로 쓸 수 없다. (b) 성격의 기록이
  하나 늘었다: "손절은 진입 시점에 예측되지 않는다"가 RSI-EMA 곡률 축에서도 성립한다
  (오히려 반대 방향).
* 만약 사용자가 「기하 대 선별」을 이 축에서 더 가르고 싶으면(고정 R 끄기·ATR 정규화 재검),
  그것은 **후속 이슈(사용자 결정)** 이고 선행은 WAN-152와 같다 — **개발자 임의 착수 금지**.
