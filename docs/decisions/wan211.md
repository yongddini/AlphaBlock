# WAN-211 — 볼린저 하단 기울기 「과열 진입 회피」 필터를 실제 손익으로 검정

WAN-209 §C 후속(사용자 결정으로 착수). §C가 상관으로 찾은 신호 — **하단 밴드(SMA20 − 2σ)가
오를수록**(σ를 위로 밀며 강세·과열) 롱 진입 **즉사**(손절 & MFE<0.5R)가 잦다 — 를 실제
**손익 게이트**로 재서, 그 거래를 걸렀을 때 **순수익이 오르는가**를 검정한다.

재현:

    python -m backtest.wan211_band_slope_filter --part null      # Part A (싼 길, 3 TF)
    python -m backtest.wan211_band_slope_filter --part pnl --timeframes 1h,4h
    python -m backtest.wan211_band_slope_filter --part pnl --timeframes 15m --append
    python -m backtest.wan211_band_slope_filter --from-csv        # 요약만 재생성
    python -m backtest.wan211_band_slope_filter --checksum        # 라벨/생산 정합 검산

좌표: 9종목 × 15m·1h·4h · 못 박은 6년 창(2020-09-15 ~ 2026-07-22) · 오늘의 채택 기본값
(핀 없음 · 필터 1.28 · `intrabar_live` · `unconditional` · 고정 1.5R · 롱 온리 · 분리 존) ·
공식 렌즈 `baseline`(+ Part B `pen_5bp` 재검). 라벨은 `wan150_labeled.csv` 재사용 ·
funding=False(WAN-150/210과 같음). 게이트 = **하단 밴드 기울기 ≥ IS 분위 문턱이면 진입
스킵**(과열 진입 회피). 원자료: `backtest/reports/wan211_{corr,death_null,pnl}.csv`,
요약 `wan211_summary.md`.

## 1. 왜 필요한가 — 상관은 손익이 아니다

WAN-209 §C는 **상관만** 쟀다. 즉사를 잘 골라내는 것과, 그 거래를 걸렀을 때 돈을 더 버는 것은
별개 질문이다. WAN-210이 정확히 같은 방향의 신호(과열 반등 회피 = 높은 RSI 진입 거르기)를
손익으로 재서 **net loss (b)** 로 닫은 선례가 있다 — 신호는 진짜였으나 게이트는 순손실이었다.
그래서 이 이슈의 첫 단계는 상관이 아니라 **손익 게이트**다(Part B).

## 2. Part A — §C를 오늘 라벨 위에서 재확인 (싼 길, 상관·매칭 널)

`wan150_labeled.csv`(핀 없는 오늘 엔진 · 9종목 · 6년 · 필터 1.28)에 하단 밴드 기울기 특징을
**탭 직전 확정봉만으로**(HTF 프레임, 서브스텝 없이) 붙여 재검한다.

### §1 게이트가 무작위 제거보다 즉사를 더 잘 줄이는가 (매칭 널)

상한 게이트(값 ≥ IS 분위 문턱 제거)를 같은 개수 무작위 제거(20시드)와 대조한다. 원자료
`wan211_death_null.csv`. 15m OOS에서 게이트 즉사율이 기본·무작위보다 낮고 `p_death`가 작다
(신호가 있음). ⚠️ 이는 §C 상관의 재확인이지 손익 근거가 아니다.

### §2 존폭·손절폭과 독립인가 (편상관, 기하 통제)

`band_lower_slope`↔즉사 상관을 `zone_width_atr`·`stop_width_atr`로 잔차화한 편상관 + 심볼
층화 순열. **판정 — §C와 일치**:

* **15m (a) 독립** — 네 특징 OOS raw +0.126~+0.130(p=0.000), 존폭·손절폭 통제 편상관도
  ÷ATR +0.107~+0.110(p=0.000) · 가격% +0.071(p≤0.003)로 살아남는다. 기하의 대리변수가
  아니다.
* **1h (c) 부분/공선** — raw는 유의(+0.08~+0.09, p≈0.03~0.05)하나 편상관이 OOS에서
  무너진다(p≈0.31~0.51). 신호의 대부분이 기하의 대리변수다.
* **4h (b)** — 유의 없음(표본 부족 · 상관 0 언저리).

**leave-one-out**(제거 1/3, 심볼 하나씩 빼고 게이트 OOS 즉사율)은 `wan211_summary.md` 참고
— §C대로 15m은 드물게 ETH 편중이 아니다.

## 3. Part B — 실제 시퀀싱 손익 (주 산출물)

게이트를 후보 단계에 걸고(값 ≥ 문턱 진입 스킵) **재시퀀싱**해 `total_return`·MDD·수익/MDD·
거래 수·즉사율을 필터 off(default)·무작위 제거(matched, 20시드)와 대조한다. 문턱은 IS 분위
(상위 1/4·1/3·1/2 전수)에서 고르고 OOS 검증. `pen_5bp` 체결 보수화 재검 포함. 원자료
`wan211_pnl.csv`.

**판정 (공식 렌즈 `baseline` OOS 심볼평균):**

* **15m (주 TF) — (b) net loss·무영향.** 필터가 무작위 제거를 이기지만(네 특징 대부분
  p=0.048) **default를 못 넘는다**: default **+37.1%** vs 필터 **+30.8~+35.4%**(12셀 전부
  default 이하, 「도움」 0/12). 즉사율은 소폭 준다(15.6% → 12.8~15.3%)나 위험조정(수익/MDD)은
  대체로 평평~소폭 악화(6.19 → 5.4~7.1). **즉사를 조금 덜 맞는 대가로 순수익이 준다** — 걸러낸
  「과열 진입」이 net으로는 양(+)의 기여자였다. WAN-210(과열 반등 회피)과 **정확히 같은 결말**.
* **1h — (c) 갈린다(위험조정 한정).** 필터가 무작위를 이기고(p=0.048) 위험조정은 개선하나
  (수익/MDD 3.14 → 3.7~4.1, MDD가 수익보다 더 준다) **raw 순수익은 default(+18.4%)를 못
  넘는다**(필터 +14.5~+18.5%, 「도움」 2/12). §2에서 1h 편상관이 붕괴한 것과 정합 — 1h에서
  게이트가 하는 일은 대부분 기하(넓은 존·손절) 제거다.
* **4h — ⚠️ 판정 불가(대조군).** 20건 게이트에 대부분 종목이 걸려 유효 종목이 1~3개뿐이라
  심볼평균이 소수에 기댄다(WAN-143 표본 게이트).

**`pen_5bp`(체결 보수화) 재검**: 15m에서 필터가 default를 못 넘는 결론이 유지된다(default
+25.2% vs 필터 +22.7~+28.5%, 일부 고제거 셀만 근소 상회). 낙관 렌즈를 벗겨도 「걸러서 더
번다」가 성립하지 않는다.

## 4. 결론

**주 TF(15m)는 (b) net loss·무영향으로 닫는다.** WAN-209 §C가 찾은 신호는 진짜다 — Part A가
같은 오늘 라벨 위에서 재확인했다(게이트가 즉사를 무작위보다 잘 줄이고, 존폭·손절폭 통제
편상관도 15m에서 살아남는다). **그러나 그 신호로 진입을 걸러도 순수익은 오르지 않는다** —
걸러낸 「과열 진입」이 net으로는 양의 기여자였기 때문이다. 즉사를 잘 골라내는 것(§C·Part A)과
그 거래를 걸렀을 때 돈을 더 버는 것(Part B)은 별개 질문이고, 답은 **아니오**다. 1h는 위험조정만
개선(raw 미개선)이라 (c), 4h는 표본 붕괴로 판정 불가다.

이는 WAN-210(과열 반등 회피, tap_rsi/RSI-EMA 상한 게이트)이 net loss (b)로 닫은 것과 **정확히
같은 결말**이고, WAN-123이 RSI 재탭 게이트를 순손해라서 제거한 것과도 통한다 — **진입 시점의
「과열」 신호로 롱을 거르는 시도가 이 저장소에서 반복 실패한다.**

**기본값·토대 불변** — 측정 전용, `ALPHABLOCK_LIVE_TRADING=false` 유지. 채택·재-베이스라인이
아니다(개발자 임의 착수 금지).
