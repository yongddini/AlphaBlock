# WAN-438 — 스토캐스틱 팔 + 몰림 규칙을 현물 1분봉으로 6년 창 밖(2018 하락장 · 2020-03 폭락)에 넣는다

**판정: 창 밖 최악은 6년 창보다 깊다.** 페이퍼 좌표(%K<25 · 몰림 중 BTC 4h ≤ −2.5% · 거래당 2%)는
**2020-03 폭락 구간(2020-02~04)에서 평가손 MDD 35.1%**(손절가 체결) · **40.9%**(손절이 그 1분 저가에
체결)를 냈고, 하루 최악은 **2020-03-12 −31.6% / −37.2%**다. 창 밖 전체(2018-01~2020-08)의 MDD는
**36.0% / 42.1%**로 WAN-436 6년 창의 32% / 38%보다 크다(종목·시장이 달라 셀 비교는 아니다).

* 🚨 **이것도 「최소 이만큼」이다** — 대조 구간(2020-09~2021-09)에서 현물 MDD가 선물보다 네 팔 전부
  **2.5~5.4%p 얕았다**(같은 분에 바닥이 났는데도). 선물로 환산하면 폭락 MDD는 **약 38~46%** 범위로 읽는다.
* 🚨 **BTC 게이트는 폭락을 막지 못한다 — 설계상 폭락 한가운데에서 문을 연다.** 2020-03-12의 몰림(11+)
  후보 **59건 전부**가 게이트(BTC 4h ≤ −2.5%)를 통과했다. 게이트 팔과 게이트 없음 팔의 폭락 MDD가
  **35.1% 대 35.1%**로 같다. 게이트는 창 밖 전체에서만 약간 앞선다(36.0% 대 39.4%).
* 🚨 **「24h 예산 10」은 하루 리스크를 10단위로 묶지 않는다.** 크기 `min(1, 10/(n+1))`을 신호가 도착할
  때마다 따로 매기므로 합이 조화급수로 자란다 — 2020-03-12 하루에 **50거래 · 14종목 · 46건 손절 · 예산
  합 17.2단위**(× 2% ≈ 34%)가 그날 −31.6%의 정체다. 규칙은 WAN-436 그대로 고정했고 **고치지 않았다**
  (결과를 보고 규칙을 옮기지 않는다 — WAN-161). 바꿀지는 사용자 결정이다.
* **2018 하락장은 낙폭보다 손실이 문제다** — 44거래 · MDD 15.6% · 거래당 −0.18R · −14.8%. 폭락이 없고
  천천히 잃는다.
* **%K<30은 모든 구간에서 더 나쁘다**(폭락 MDD 38.8% · 창 밖 전체 41.5%) — 6년 창에서 본 방향과 같다.
  민감도이지 고르는 자리가 아니다.

**채택 권고 없음 · 기본값·토대 불변 · 페이퍼 규칙(WAN-435)도 건드리지 않았다.**

## §6 배선 — 러너를 고치지 않았다

* 현물 봉은 **선물 표기**(`BTC/USDT:USDT`)로 별도 루트에 적재하고, 측정은 그 루트를 **작업 디렉터리로**
  삼아 돈다(러너가 상대경로 `data/ohlcv.db`를 읽는다 · `working_root`). 그래서 엔진·러너(`wan169`) 코드는
  **한 줄도 안 바뀌고** 선물 payload 캐시도 안 깨졌다. 현물 payload 캐시는 루트 아래 **별도 디렉터리**다.
* base 후보 인자는 **`wan424.base_cell_kwargs`**(신설) 한 곳에서 읽는다 — `build_base_payloads`도 그것을
  쓴다(두 벌 금지 · 테스트가 호출 인자로 고정). `wan436.build_entries`에 창·%K 문턱 옵트인 인자를 더했다
  (기본값이면 예전과 같다).

엔진·러너 코드 무수정 · 운영 DB 불변 WAN-194 · 핀 없음 WAN-305) · 이 팔은 **채택 좌표가 아니다** ·
